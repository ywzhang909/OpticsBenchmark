## 核心内容

### 背景与目标
- **研究背景**：降维（DR）技术广泛用于高维数据分析，但其非线性特性使得特征贡献无法反向追踪。现有解释方法多仅关注低维投影空间或忽略特征间的交互作用，难以量化各特征对降维后簇形成的具体贡献，限制了探索性分析的深度。
- **本文目标**：提出ClusterShapley方法 → 通过基于聚类导向的Shapley值近似估算与多维协调可视化机制 → 实现对降维结果中特征对簇凝聚/分离贡献的可解释性量化与交互式探索。

### 研究内容
- **技术路线**：输入高维数据集($\mathbb{R}^m$) → 降维至二维可视化空间($\mathbb{R}^2$) → 用户手动圈选或算法自动划分散点图中的视觉聚类 → 将簇标签映射回高维空间 → 计算样本到各簇质心的欧氏距离并进行L1归一化生成簇概率 → 基于训练集拟合KernelSHAP线性模型，对测试集（20%）估算Shapley值 → 输出特征贡献矩阵 → 通过多视图可视化系统（散点图-点图联动、工具提示、重要性汇总/热力图）支持假设生成。
- **关键方法**：
  1. **聚类导向的Shapley值估算（ClusterShapley）**：突破传统全局重要性评估，将“二维投影中的簇分布”定义为解释目标模型。通过距离-概率转换与KernelSHAP近似计算，量化每个高维特征对特定簇形成的边际贡献（负值表示促进簇凝聚，正值表示导致分离），有效捕捉特征交互与局部结构。
  2. **多视图协调可视化设计**：设计分层编码策略：工具提示采用分位数直方图交替编码特征值高低与Shapley贡献；详细分析页提供点图与核密度估计（KDE）联动，直观展示特征值分布与贡献度强弱的非线性关系；重要性热力图结合层次聚类与最优叶序排序，快速定位跨簇特征异质性。

### 实验内容
- **数据**：共6个公开真实数据集，涵盖医学、社会科学与高维文本领域：
  1. `Iris`：150样本/4维（基线验证）
  2. `Vertebral Column`：310样本/6维（脊柱生物力学特征）
  3. `Indian Liver`：167样本/10维（肝病临床指标）
  4. `Red Wine Quality`：1599样本/11维（理化指标与质量评分）
  5. `Communities and Crime`：2215样本/128维（社区社会经济指标）
  6. `CBR-ILP-IR`：574文档/18694维（TF-IDF词频矩阵，万维验证）
- **实验设计**（含复现参数与环境）：
  - **硬件环境**：Intel Core i7-8700 @3.20GHz，32GB RAM，Windows 10 64位。
  - **软件与参数**：降维工具使用 `sklearn` 实现的 t-SNE 或 `umap-learn`；Shapley估算采用 `KernelSHAP`；训练/测试集按 `80/20` 划分；距离转换使用 L1 归一化；热力图排序使用最优叶序（optimal-leaf-ordering）与层次聚类。
  - **实验系统结构**：数据加载模块 → 降维与簇标注（手动交互/算法自动） → 簇概率生成器 → KernelSHAP估算器 → 多视图渲染引擎（含工具提示、点图、重要性条形图、热力图）。
  - **实验设置分类**：
    1. **医学案例实验**：Vertebral Column与Indian Liver，验证特征贡献与临床病理的语义一致性。
    2. **理化/社会案例实验**：Red Wine与Communities and Crime，验证跨领域可解释性与特征交互发现能力。
    3. **高维/自动聚类对比实验**：CBR-ILP-IR，测试万维数据下 k-Means(4/8簇)与凝聚聚类的导入兼容性及计算扩展性。
- **实验结果**：
  - **评估指标**：定性语义验证（特征-现象对应合理性）、定量计算耗时（秒）、解释一致性（手动vs自动聚类）。
  - **基线对比**：与ccPCA、PCA/LDA重要性方法对比，指出基线仅返回独立特征重要性，无法反映特征交互与局部簇贡献；ClusterShapley通过加性Shapley值与可视化联动，实现“值-贡献”相关性洞察。
  - **消融/设置效果**：手动标注聚类可保留降维原始视觉结构，自动聚类在高质量投影下可复现相似特征模式（如CBR-ILP-IR中跨簇共享术语识别）；计算耗时随维度与簇数线性增长，表1数据显示万维数据仅需1.1~1.6秒（574样本），中等数据集<3秒，高维文本约1.2秒。
  - **核心发现数值/现象**：
    - 脊柱滑脱程度特征对簇凝聚的Shapley贡献绝对值最高，且高特征值对应负贡献（促进簇形成）。
    - Indian Liver数据中，碱性磷酸酶高值簇与转氨酶异常簇在Shapley分布上呈现互补模式，成功区分胆道阻塞与肝炎亚型。
    - 红酒数据中，氯化物/硫酸盐特征在特定簇的Shapley值显著为负，定量解释了“高盐风味簇”的物理化学成因。

### 核心结论
1. **首次验证Shapley值在降维解释中的有效性**：ClusterShapley成功将博弈论中的加性特征重要性引入非线性降维分析，量化了特征对投影簇形成的边际贡献，填补了降维不可逆导致特征追踪困难的理论空白。
2. **多视图联动机制显著提升探索性分析效率**：实验证实“特征值-贡献度”相关性可通过交互可视化直观呈现，帮助分析师在医学、社会科学及文本数据中生成可验证的假设（如病理亚型区分、理化风味成因），验证了初始假设（可解释降维结果能直接驱动领域洞察）。
3. **适用性强但受计算复杂度制约**：方法在数百至万维数据集上均能稳定运行并产出合理语义解释，但Shapley近似估算耗时与样本量、特征维度及簇数量呈正相关。未来需开发分层采样、并行计算或模型专用近似策略以突破大规模数据的应用瓶颈。
