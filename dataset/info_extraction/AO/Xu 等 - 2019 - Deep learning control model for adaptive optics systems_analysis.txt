## 核心内容

### 背景与目标
- **研究背景**：传统自适应光学(AO)系统依赖哈特曼-夏克(HS)波前传感器与变形镜，常规PI控制严格依赖变形镜的响应矩阵。实际系统中，传感器与变形镜间的空间对齐误差（平移、旋转）会导致响应矩阵失准，传统方法需频繁重新校准且无法彻底消除误差，严重影响系统稳定性与校正精度。
- **本文目标**：提出深度学习控制模型(DLCM) → 通过模型网络与执行者网络参数共享机制及基于波前斜率的代价函数梯度优化 → 实现无需校准响应矩阵的在线识别、自自适应控制与高精度波前校正。

### 研究内容
- **技术路线**：输入(HS传感器子孔径波前斜率数据) → 深度自然网络(DNN)前向传播映射 → 模型网络(M)预测控制电压并稳定输出 / 执行者网络(A)实时输出最优电压 → 代价函数(J监督学习/ J0在线优化) → AGD梯度优化算法更新网络参数 → 输出控制电压驱动变形镜 → 闭环自适应波前校正。
- **关键方法**：
  1. **双网络架构与参数共享机制**：模型网络基于决策样本空间进行监督学习，负责快速收敛与稳定控制电压；执行者网络以最小化波前残差为目标，直接输出高精度控制量。两者通过公式 $\theta_a \leftarrow \tau\theta_m + (1-\tau)\theta_a$ 共享参数，超参数 $\tau$ 用于调节系统增益，兼顾收敛速度与校正精度。
  2. **融合二阶导数信息的加速梯度下降(AGD)算法**：结合Nesterov加速梯度(NAG)与AdaDelta的优点，引入历史梯度变化趋势与参数更新均方根误差(RMS)自适应调节各参数学习率。该算法避免学习率过快衰减，显著提升网络训练效率与收敛稳定性。

### 实验内容
- **数据**：数值仿真数据。使用Zernike多项式前35阶随机生成的100组初始波面(W₁~W₁₀₀)作为校正目标。系统为61单元变形镜阵列，HS传感器由12×12微透镜阵列（112个有效子孔径）与288×288像素CCD组成，控制计算延迟为3个采样周期。
- **实验设计**（指导复现参数）：
  - **网络结构**：模型网络与执行者网络结构相同，2个隐藏层，每层224个神经元，隐藏层激活函数ReLU，输出层线性激活。
  - **超参数设置**：参数共享系数 $\tau=0.98$，决策样本空间队列容量900，学习率与动量系数依AGD动态调整。
  - **环境/系统参数**：变形镜执行器间距设为 $d$；仿真波长 $\lambda=632.8\text{ nm}$；代价函数 $J_0 = \frac{1}{N}\sum_{i=1}^N (G_{X,i}^2 + G_{Y,i}^2)$（$N$为子孔径数，$G_X, G_Y$为斜率）。
  - **实验分组**：
    1. **固定PI响应矩阵组**：不重新校准PI矩阵，直接模拟不同对齐误差（$\Delta x, \Delta y = 0, \pm2d/10, \pm4d/10$；旋转角 $\alpha = 0, \pm3^\circ, \pm6^\circ$），对比PI与DLCM闭环性能。
    2. **重新校准PI响应矩阵组**：每次改变对齐误差后重新测量并校准PI响应矩阵，对比两者性能。
- **实验结果**：
  | 实验设计/条件 | 数据与参数设置 | 核心结果 |
  |---|---|---|
  | **无对齐误差(基准)** | $\Delta x=\Delta y=\alpha=0$；100组波面蒙特卡洛验证 | DLCM仅需8次迭代即收敛，平均$J_0$降至0.109；PI需23次迭代，$J_0$为0.221。DLCM校正精度与速度均占优。 |
  | **固定PI矩阵+平移误差** | $\Delta x/\Delta y$ 逐步增大至 $\pm4d/10$；$\alpha=0$ | PI矩阵失准导致闭环发散或SR骤降；DLCM通过在线学习自动补偿，闭环始终稳定，平均SR显著高于PI。 |
  | **固定PI矩阵+旋转误差** | $\alpha$ 逐步增大至 $\pm6^\circ$；$\Delta x=\Delta y=0$ | PI在 $\alpha \ge \pm4^\circ$ 时出现不稳定；DLCM保持高容错率，收敛过程平滑，校正后SR稳定在高位。 |
  | **重新校准PI矩阵** | 每次误差改变后重测响应矩阵；保持PI控制参数不变 | 校准后PI性能恢复，但DLCM迭代次数仍更少（平均8次 vs PI约15-20次），且DLCM无需额外校准步骤，综合控制性能更优。 |
  | **算法优化对比** | AGD vs 传统梯度下降(GD)训练模型网络 | AGD收敛仅需120次迭代，GD需835次，训练效率提升约7倍，验证了二阶导数信息对收敛速度的加速作用。 |

### 核心结论
1. **成功摆脱响应矩阵依赖**：DLCM通过在线学习与参数共享机制，有效克服了HS传感器与变形镜的对齐误差，无需频繁校准响应矩阵即可实现系统自适应控制，验证了初始假设。
2. **收敛速度与精度双提升**：AGD优化算法利用梯度变化趋势与自适应学习率，使网络训练收敛速度提升约7倍；参数共享机制使模型网络与执行者网络优势互补，兼顾快速收敛与高控制精度。
3. **强鲁棒性与工程实用潜力**：在平移与旋转对齐误差下，DLCM均表现出优异的稳定性、高Strehl比值校正效果与宽容忍度，显著优于传统PI控制，为复杂光学系统的高实时自适应校正提供了新范式。
