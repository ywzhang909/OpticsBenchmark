## 核心内容

### 背景与目标
- **研究背景**：传统自适应光学（AO）主要校正相位与偏振像差，但光束传播、材料二向色性吸收或生物组织散射引起的空间强度非均匀误差会严重破坏波前干涉与聚焦质量，而现有强度校正技术仍处空白。
- **本文目标**：提出强度自适应光学（I-AO）方法 → 通过“波前强度均匀化主环+总能量恢复次环”的双反馈闭环机制 → 实现瞳孔平面绝对强度分布校正与衍射极限焦点质量恢复（兼容传感器基与无传感器双模态）。

### 研究内容
- **技术路线**：含强度误差的光束输入 → 波前/焦点图像数据采集（直接成像/间接序列） → 强度误差反演与模式匹配（预补偿计算/强度泽尼克优化） → 双反馈执行（SLM强度预校正+DM相位补偿 → 衰减器能量标定） → 输出均匀强度光场与理想艾里斑焦点。
- **关键方法**：
  1. **双反馈闭环控制机制**：突破传统单环AO架构。主反馈环（SB1/SL1）负责非均匀强度分布的像素级校正，并同步利用变形镜（DM）消除SLM引入的几何相位误差及系统残余相位像差；次反馈环（SB2/SL2）独立调节光源后衰减器，将整体光强精准恢复至参考基准值，实现“相对均匀”到“绝对强度”的完整补偿。
  2. **强度泽尼克模式（Intensity Zernike Modes）与无传感器反演算法**：针对强度属能量相关量、无法直接套用传统正交相位Zernike模式的难题，定制开发新型强度校正基函数。算法单次独立施加各模式系数，结合“图像低空间频率含量”与“光斑圆度”双指标构建优化目标，在无直接强度传感器的条件下实现误差梯度搜索与最优校正参数收敛。

### 实验内容
- **数据**：
  - **可控误差源**：SLM夹于正交偏振片间生成的任意空间强度分布。
  - **真实生物样本**：纤维化组织切片。
  - **真实材料样本**：双折射晶体。
  - **来源与特点**：覆盖系统级人工引入、生物组织天然散射/吸收、材料偏振/二向色性损耗，具备多场景代表性。
- **实验设计**（含可复现光路结构）：
  - **系统组成**：激光光源 → 衰减器 → 强度误差源 → I-AO校正器（SLM夹正交偏振片） → 变形镜(DM) → 分束镜(DM) → 高NA物镜 → 焦点成像相机/波前传感器。
  - **传感器基I-AO**：单色相机直接捕获波前平面强度 → 计算 retardance 预补偿图 → SLM执行 → DM执行无传感器相位AO → 调整衰减器匹配参考总强度。
  - **无传感器I-AO**：焦点相机捕获图像序列 → 依次加载15组强度泽尼克模式及振幅 → 双指标联合优化选定最优模式/系数 → SLM执行 → DM相位精细校正 → 衰减器能量恢复。
  - **对比设置**：基线为“I-AO关闭+仅开启相位AO”及“无误差理想状态”；验证实验分三步递进（强度校正→相位校正→能量恢复）。
- **实验结果**：
  - **主要评估指标**：波前平面强度均匀性、焦点截面强度分布轮廓、聚焦质量（Strehl比定性表征）、绝对光强恢复精度。
  - **基线模型**：传统无传感器相位自适应光学（Phase AO on）、未校正状态（I-AO Off）。
  - **消融实验设置**：依次隔离主环强度校正、主环相位校正、次环能量恢复三个阶段，验证各环节贡献。
  - **性能提升**：截面强度分布由“严重畸变/拖尾”恢复至“平滑对称的理想艾里斑轮廓”；强度非均匀性误差被完全消除；总光强经次环补偿后与初始参考值完全一致，系统聚焦分辨率与成像对比度显著提升。

### 核心结论
1. **首次验证强度像差校正的独立价值**：传统相位AO无法解决波前平面空间强度非均匀问题，I-AO有效填补了强度校正技术空白，完全验证了初始假设。
2. **双环解耦实现“均匀性+绝对强度”全补偿**：主环解决相对分布均匀化与几何相位耦合，次环独立恢复绝对能量水平，解耦设计避免了能量调制对相位校正的干扰。
3. **双模态架构具备强泛化性与工程潜力**：传感器基与无传感器I-AO在人工及真实生物/材料样本中均取得等效性能提升，为高分辨显微成像、病理诊断及复杂光学系统提供了可即插即用的新一代校正工具。（注：未出现颠覆性意外发现，但明确指出了未来结合深度学习或分区校正可进一步提升无传感器精度。）
