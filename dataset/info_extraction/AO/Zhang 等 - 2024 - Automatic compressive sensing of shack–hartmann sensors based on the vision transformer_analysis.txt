## 核心内容

### 背景与目标
- **研究背景**：Shack-Hartmann波前传感器（SHWFS）在自适应光学系统中易受导星亮度低或强大气湍流干扰，导致波前重建精度下降；传统CNN模型共享卷积核难以区分子孔径信噪比差异，且现有压缩感知方法依赖人工筛选或迭代计算，缺乏环境自适应能力。
- **本文目标**：提出Vision Transformer模型 → 通过多头自注意力机制结合子孔径光斑图像与二维位置信息进行动态权重分配 → 实现高鲁棒性、高精度的自动压缩感知与端到端波前重建。

### 研究内容
- **技术路线**：SHWFS光强图像输入 → 网格分割为子孔径光斑序列 → 全连接层映射为特征嵌入向量并与位置编码拼接 → Vision Transformer编码器（多头自注意力机制）计算注意力权重矩阵 → 层归一化与矩阵展平 → 多层全连接网络 → 输出变形镜（DM）控制向量。
- **关键方法**：
  1. **基于ViT的自适应子孔径权重分配机制**：利用自注意力计算查询(Q)、键(K)、值(V)矩阵，生成注意力映射图（Attention Map）。该机制能根据子孔径的实际信噪比和空间位置自适应分配权重，自动“过滤”低质量光斑并保留高阶像差信息，解决CNN全局共享卷积核无法差异化处理子孔径的缺陷。
  2. **端到端DM控制向量直接输出**：摒弃传统方法中先计算斜率再拟合Zernike系数的分步流程，模型直接输出变形镜控制向量，避免高阶系数截断误差，更贴合自适应光学硬件驱动需求。

### 实验内容
- **数据**：基于Soapy自适应光学模拟平台生成数据集。训练集70,000张（R0∈[0.12, 0.18)，视星等u∈[8, 16)）；验证集10,000张。测试集分为两组：固定R0=0.2.变化视星等（8~18，每级1000张）；固定视星等=8变化R0（0.05~0.20，每档1000张）。系统配置：8m望远镜，16×16子孔径（208有效），17×17变形镜（285有效致动器），导星波长600nm，科学像波长1650nm。
- **实验设计**：
  - **软硬件环境**：训练端NVIDIA Quadro P5000 GPU + 96GB RAM (TF 2.5.0/Py 3.9)；测试端Tesla K40c GPU + 31GB RAM (TF 2.9.1/Py 3.7)。
  - **预处理策略**：所有数据划分为“含归一化（Nor）”与“不含归一化（No Nor）”两组独立训练。
  - **优化设置**：SGD优化器（防梯度爆炸），MAE损失函数，Dropout(0.2)，学习率自适应衰减(ReduceLROnPlateau)，EarlyStopping。每种配置独立重复训练10次以消除随机性。
  - **评估指标**：斯特列尔比(Strehl ratio)、均方根误差(RMS)、峰谷值(PV)、点扩散函数(PSF)能量集中度、单帧推理速度。
- **实验结果**：

| 实验配置 | 数据与环境特点 | 核心结果与性能对比 |
|:---|:---|:---|
| **CNN (ResNet) + 归一化** | 覆盖全范围R0与视星等测试集 | 归一化显著提升CNN；低湍流下Strehl比提升最高达0.2；整体平均Strehl比比ViT低约0.2 |
| **CNN (ResNet) + 无归一化** | 同上 | 性能最弱；高湍流/低亮度下Strehl比仅~0.106，RMS/PV值偏高 |
| **ViT + 归一化** | 同上 | 低湍流(R0>0.12)/高亮度(视星等<11)时表现优异，Strehl比最高达0.824；但高湍流/低亮度时性能衰减(Strehl比降至~0.05) |
| **ViT + 无归一化** | 同上 | 高湍流(R0<0.12)/低亮度(视星等>11)时表现最佳；整体平均性能最稳，验证集MAE均值0.498，显著优于CNN(0.639) |
| **复现性与效率验证** | 每种配置训练10次模型 | ViT无归一化配置验证集MAE标准差最小(0.0046)，泛化最稳；ViT单帧推理2.856ms，CNN为3.363ms，ViT延迟更低 |

### 核心结论
1. **ViT模型全面超越传统CNN**：在任意大气湍流强度和导星亮度条件下，基于Vision Transformer的自动压缩感知方法在波前重建精度（Strehl比、RMS/PV）与鲁棒性上均稳定优于ResNet等CNN模型，平均提升约0.2的Strehl比，验证了初始假设。
2. **归一化预处理的作用具有环境依赖性**：数据归一化能有效提升CNN性能，但对ViT的影响呈分化趋势。在低湍流/高亮度条件下可进一步改善ViT（Strehl比可达0.8），而在高湍流/低亮度条件下反而导致性能骤降（Strehl比~0.05），表明ViT的自注意力机制能自适应解析原始光强分布，无需强制归一化。
3. **自注意力机制实现高效自动压缩感知**：ViT无需人工筛选或迭代计算，即可结合位置与图像信息动态分配子孔径权重，有效抑制低信噪比噪声并保留高阶像差信息。该方法为SHWFS及其他具有稀疏性的波前传感器（如金字塔波前传感器）提供了免调参、高精度的实时重建新范式。
