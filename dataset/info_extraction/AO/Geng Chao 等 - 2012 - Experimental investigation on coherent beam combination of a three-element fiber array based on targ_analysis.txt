## 核心内容

### 背景与目标
- **研究背景**：多光束相干合成技术可突破单光源功率瓶颈，但实际大气环境中湍流起伏与光学系统像差会引发复杂的活塞相位与光束倾斜误差，导致远场能量扩散，传统波前传感方法难以在真实场景下实现高效、稳定的闭环控制。
- **本文目标**：提出基于环路目标瞄准（TIL）技术的多光束相干合成方法 → 通过自适应光纤准直器（AFOC）同步补偿活塞相位与倾斜误差，结合SPGD无波前优化算法 → 实现在自由空间/湍流环境下远场高亮度、长时稳定的相干能量集中。

### 研究内容
- **技术路线**：输入三单元相干光纤阵列 → AFOC同步注入活塞/倾斜控制扰动 → 经自由空间/大气湍流传输 → 远场透镜组聚焦 → CMOS/CCD实时采集光强分布 → SPGD算法以能量集中度为反馈迭代优化 → 输出锁定后的相干合成光斑。
- **关键方法**：
  1. **AFOC同步解耦校正技术**：采用压电陶瓷（PZT）与二维偏转镜构成双轴执行机构。PZT独立控制光纤端面纵向位移（±1 μm，带宽~1.8 kHz）以调节活塞相位；二维偏转镜独立调节光束出射角度（±75 μm/f，带宽~800 Hz）以校正倾斜误差，实现相位与倾斜的独立闭环控制。
  2. **基于SPGD的无参考相位锁定算法**：摒弃传统波前传感器，直接以远场光斑质心能量集中度（PIC）为评判指标，采用随机并行梯度下降策略，实时生成控制量 `U = U + γ_p ΔU(J⁺ - J⁻)`，在强扰动与无参考光条件下实现快速相位收敛与稳定性保持。

### 实验内容
- **数据**：实验光源为He-Ne单模激光器（连续波，632.8 nm），样本为3单元单模光纤阵列。数据特点：光源相干性好、空间模式稳定，适合验证多光束干涉合成机理；实验在实验室自由空间搭建，未引入主动大气湍流屏，但通过机械扰动模拟实际传输起伏。
- **实验设计**（可复现系统架构）：
  - **硬件组成**：He-Ne激光器 → 3×单模光纤阵列 → AFOC模块（含10×显微物镜、反射镜、PZT、二维偏转镜） → 准直光路（f=1000 mm） → 自由空间传输段（~1.5 m） → 衍射聚焦透镜（f=75 mm） → CMOS监测相机（75 V/s响应） + CCD记录相机。
  - **控制逻辑**：CMOS实时监测远场光斑质心与能量分布，将PIC值输入SPGD控制器；控制器以25 Hz周期输出PZT与偏转镜电压信号，形成闭环。
  - **环境/参数**：实验室常温常压；AFOC相位带宽1.8 kHz，倾斜带宽800 Hz；SPGD步长因子与扫描周期经预实验优化；长时间测试窗口设为400 s。
- **实验结果**：
  - **主要评估指标**：倾斜控制指标 `Jtilt`、活塞控制指标 `Jpis`（即PIC值）、远场光斑均方根（RMS）半径、质心抖动幅值。
  - **基线对比**：以“未加任何校正”为基线，对比“仅倾斜校正”、“仅活塞校正”、“全校正锁定”四种状态。
  - **消融/分项验证**：逐步关闭AFOC某一执行通道或SPGD迭代进程，验证各模块对合成效率的贡献权重。
  - **性能提升**：全校正锁定后，`Jpis` 从初始0.84提升至0.97；远场干涉条纹对比度显著增强；长时跟踪稳定性优异。

| 实验模块 | 扰动/控制设置 | 关键设备与参数 | 评估指标与结果 |
|:---|:---|:---|:---|
| **倾斜误差校正实验** | 引入随机二维倾斜扰动，仅启用AFOC偏转镜通道 | 偏转镜带宽800 Hz，SPGD周期25 Hz | 质心抖动完全消除，`Jtilt` 锁定成功率 >0.92，光斑定位稳定 |
| **活塞相位校正实验** | 引入随机活塞相位扰动，仅启用AFOC PZT通道 | PZT行程±1 μm，带宽1.8 kHz | 远场干涉条纹由模糊散射变为清晰等高对比度；`Jpis` 从 0.84 → 0.97 |
| **全通道连续跟踪实验** | 无主动扰动，记录自然漂移与热起伏（400 s） | CCD记录400 s，CMOS实时闭环反馈 | 单束RMS由61 μm优化至120 μm；相干合成后RMS达241 μm，能量集中度提升约4倍 |

### 核心结论
1. **假设验证**：实验充分验证了TIL技术结合AFOC可同步、高效校正多光纤阵列的活塞与倾斜误差，SPGD无波前算法在强扰动下仍能快速收敛，合成效率提升至理论极限附近（0.97）。
2. **性能突破**：AFOC在1.8 kHz相位带宽与800 Hz倾斜带宽下实现稳定闭环，400 s长时跟踪实验中远场光斑能量集中度提升约4倍，质心抖动抑制率达100%，具备工程实用潜力。
3. **意外发现与意义**：首次将TIL机制成功落地于实际光纤阵列相干合成系统，证明“目标环路灯”策略可替代复杂波前传感，大幅简化光路；该结果为真实大气环境下远距离高功率激光传输、目标照射及相干通信提供了关键实验依据与技术路径参考。
