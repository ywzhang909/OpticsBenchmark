## 核心内容

### 背景与目标
- **研究背景**：大型空间望远镜受限于单镜加工与发射能力，普遍采用多子镜拼接（稀疏孔径）结构，但子镜间的光程差（Piston误差）会严重破坏相干叠加与成像质量；传统基于物理模型与特定传感器的共相调节方法在宽动态范围、非线性映射及迭代收敛速度上存在瓶颈，亟需高效、鲁棒的新技术。
- **本文目标**：提出一种基于预训练卷积神经网络与CBAM的稀疏孔径镜面全局活塞误差调制方法 → 通过引入通道与空间双路径注意力机制及数据泛化策略 → 实现低标注数据依赖、宽动态范围、高精度（<λ/80）的波前相位感知与闭环快速调节。

### 研究内容
- **技术路线**：输入共相传感器图像（色散条纹/窄带远场光斑） → 图像裁剪拼接与高斯噪声泛化 → CBAM通道/空间注意力特征提取 → 预训练CNN主干网络（18层） → MSE损失优化与真实数据微调 → 输出活塞误差预测值 → 闭环迭代相位调节。
- **关键方法**：
    1. **CBAM-CNN特征提取架构**：在卷积层间嵌入串联的通道注意力（融合平均池化与最大池化，通过MLP权重分配）与空间注意力（7×7卷积+Sigmoid），自适应增强关键特征权重，有效抑制随机噪声与冗余背景信息，提升非线性映射能力。
    2. **预训练与数据泛化机制**：基于Fraunhofer衍射与傅里叶光学原理构建高保真光学仿真模型，通过图像堆叠打破单张图像的旋转对称性歧义，并引入多SNR高斯噪声构建泛化数据集；先在大规模仿真数据上预训练学习全局特征映射，再迁移至少量真实实验数据进行快速微调，大幅降低对高昂标注数据的依赖。

### 实验内容
- **数据**：
    - **仿真数据**：色散条纹（误差范围[-20, 20] μm）与窄带远场光斑（误差范围[-0.1875, 0.1875] μm）各48,000张，SNR=10，划分比例4:1:1。
    - **真实实验数据**：通过压电驱动的拼接镜实验系统采集2,000张，划分为训练集30,000（泛化扩展）、验证集7,500、测试集3,000张；另留1,200张用于最终独立验证。
- **实验设计**（含复现关键参数）：
    - **光学硬件系统**：光纤光源（色散条纹λ=633 nm，远场λ=532 nm）→ 准直透镜（孔径25.4 mm）→ 拼接镜组件（压电陶瓷驱动器，行程[-8, 8] μm，分辨率40 nm）→ 分光镜/色散组件/透镜组 → 高分辨率CCD相机（分辨率240×240 & 54×54）。
    - **共焦验证**：采用嵌套环形/中心镜模拟子镜，迭代调节位移致动器使远场光斑中心重合（误差<0.5像素，横向对准Δx,y<λ/6）。
    - **网络训练配置**：Python 3.8 + TensorFlow 2.6.0 + Keras 2.6.0，硬件为Intel i7-10700 CPU + NVIDIA RTX 2080 GPU。优化器Adam，动态学习率(1e-3→1e-5)，Dropout+数据增强(±10°旋转, ±5%平移)。损失函数MSE。
    - **闭环仿真**：Monte Carlo测试，初始误差服从N(0, 10μm)，截断[-15, 15]μm，叠加SNR=10噪声，最大迭代10次，执行100次独立仿真。
- **实验结果**：(见下表)

| 实验类别 | 实验设计与数据 | 关键结果与性能提升 |
| :--- | :--- | :--- |
| **仿真预训练实验** | 输入48k张仿真色散条纹/远场图像，SNR=10；训练2000/1000 epoch | 收敛快（~1800/950 epoch）；RMSE分别为 41.77 nm (色散) 与 2.38 nm (远场) |
| **真实数据微调实验** | 输入2k张真实采集图像扩展至4.05万组，微调400/200 epoch | 泛化能力强；RMSE降至 41.41 nm (色散) 与 2.77 nm (远场)，满足工程精度 |
| **鲁棒性与消融对比** | 噪声SNR=10/8/5/4；对比基线：ResNet18, VGG16, BP-Net, 消融CBAM-CNN | SNR≥5时鲁棒稳定；CBAM使色散条纹RMSE较ResNet/VGG提升14.6%/37.3%，远场提升4.2%/17.5%；消融后精度骤降证实模块必要性 |
| **闭环Monte Carlo仿真** | 初始误差N(0,10μm)，SNR=10，最大迭代10次，100次独立测试 | 收敛残差全部分布于[0, 8] nm，97%工况<6 nm；单次推理仅0.5796 ms，验证高精度与实时性 |

### 核心结论
1. **验证了数据驱动范式的工程可行性**：成功验证了“预训练+注意力机制+数据泛化”可有效突破传统传感器在宽动态范围与非线性映射上的瓶颈，实现高保真Piston误差感知。
2. **性能显著优于基线且具强鲁棒性**：CBAM-CNN在色散条纹与窄带远场光斑上的预测精度分别达到41.41 nm与2.77 nm，显著优于ResNet/VGG/BP等传统网络，并在SNR≥5的中等噪声环境下保持稳定。
3. **满足工程级闭环控制指标**：闭环Monte Carlo测试表明该方法具备极快的推理速度（<0.6 ms/次）与极高的收敛精度（残差<8 nm，97%<6 nm），完全满足<λ/80的精细共相调节要求，为大口径稀疏孔径望远镜的波前传感与控制提供了可落地的高效技术路径。
