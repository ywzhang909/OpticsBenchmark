## 核心内容

### 背景与目标
- **研究背景**：高功率固体板条MOPA激光器受增益介质窄尺寸与冷却条件限制，泵浦不均与ASE效应易引发显著的局部波前陡坡与起伏畸变，严重劣化远场聚焦性能；传统单二维变形镜校正需极高的驱动器电压差（近100V），存在镜面损伤风险且易残留高阶像差。
- **本文目标**：提出一种基于组合变形镜的波前校正方法 → 通过一维变形镜定向分离并补偿局部起伏分量、降低驱动器间高压差，由二维变形镜专注处理剩余高阶像差的协同机制 → 实现驱动器安全性提升、波前残差均方根显著降低及远场光束质量因子优化至1.67的效果。

### 研究内容
- **技术路线**：板条MOPA激光输出 → 矩形整形扩束（60mm×5mm） → 经1D变形镜反射后二次扩束匹配（60mm×60mm） → 180fps Hartmann-Shack波前传感器实时检测畸变 → FPGA模块解算子孔径偏移矢量 → AO控制器生成驱动向量 → 1D DM校正局部高斜率起伏 → 2D DM补偿剩余高阶像差 → 闭环反馈输出 → 远场探测器采集光斑评估质量因子β。
- **关键方法**：
  1. **组合变形镜分步解耦校正**：采用11单元一维变形镜（1D DM）与67单元二维变形镜（2D DM）级联。1D DM专门针对板条光束长边方向的局部陡峭起伏进行相位补偿，使波前空间分布平滑化，从而将2D DM相邻驱动器电压差从近100V降至安全范围，避免压电陶瓷击穿风险，并有效抑制残差高阶像差。
  2. **波前模态分析与影响函数适配**：基于勒让德多项式对矩形孔径光束进行模态分解，量化校正前后各阶像差能量分布；结合1D DM仅沿单一方向变化的影响函数特性（$f_i(x,y)=e^{ln(\omega)\frac{(y-y_i)^2}{d_0^2\alpha}}$），通过参数优化实现低阶/局部畸变与全局/高阶畸变的精准分离与协同补偿。

### 实验内容
- **数据**：使用中国工程物理研究院自研板条固体MOPA激光器输出的矩形窄板条光束。采样通过HS-WFS的40×40子孔径阵列完成，光束孔径经整形后有效校正区域为60mm×60mm。
- **实验设计**：
  - **系统组成结构**：MOPA激光器 → 分束器#1 → HS-WFS（40×40子孔径，180帧/s采样） → AO控制板与FPGA图像处理器 → 高压驱动器 → 1D DM（11单元，压电陶瓷驱动，行程±3μm，单元间隔6.5mm） → 扩束系统 → 2D DM（67单元，六边形排布，压电陶瓷驱动，行程±4μm，单元间隔8.5mm） → 分束器#2 → 远场光束质量探测器。
  - **环境/设备参数**：变形镜工作波段高反膜反射率>99.85%；采用背面主动冷却控温抑制热变形；HS-WFS图像延迟约1/4帧周期传输至控制板，实现近实时闭环；采用功率在桶内（PIB）法评估远场能量集中度。
  - **复现指导**：按光路顺序搭建级联变形镜AO系统，确保1D DM光轴与板条长边方向平行；校准1D DM影响函数以消除光学路径畸变引入的误差；闭环算法以HS-WFS子孔径位移量为反馈，迭代求解驱动向量并输出至高压放大器，实时调节镜面形貌。
- **实验结果**：
  - **评估指标**：波前残差均方根(RMS)、峰谷值(PV)、远场光束质量因子β、桶内功率比例(PIB)。
  - **基线对比**：未校正板条激光 vs 单2D DM校正（理论/模拟） vs 1D+2D组合校正（真实实验）。
  - **具体数值**：单2D DM驱动相邻电压差近100V，残差RMS>0.1μm；组合校正后残差RMS<0.08μm，PV<0.5μm（100阶以下像差被高效补偿）；远场光束质量因子β从未校正的≈7.36提升至1.67，PIB达81.5%（逼近同孔径理想衍射极限）。

**实验设计、数据与结果汇总表**

| 实验配置/条件 | 系统结构与核心参数 | 关键测量数据 | 性能结果与提升 |
|:---|:---|:---|:---|
| **基线（未校正）** | 板条MOPA直出，无AO干预 | 初始波前PV大，局部高斜率与起伏显著 | 远场能量分散，光束质量因子β≈7.36 |
| **单二维变形镜校正** | 仅67单元2D DM闭环运行 | 相邻驱动器电压差近100V，残差RMS>0.1μm | 高压威胁镜片寿命，残差含较多高阶像差，校正效率受限 |
| **组合变形镜校正** | 11单元1D DM + 67单元2D DM级联闭环 | 驱动高压差大幅消除，残差RMS<0.08μm，PV<0.5μm | 100阶以下像差高效补偿，β优化至1.67，PIB达81.5%逼近衍射极限 |

### 核心结论
1. **假设验证**：成功验证了“1D+2D组合变形镜架构可有效解耦板条激光局部起伏与高阶畸变”的初始假设。分步校正机制显著降低了驱动器间的高压差，提升了系统运行安全性与闭环稳定性。
2. **性能突破**：校正后波前残差RMS<0.08μm，远场光束质量因子β由7.36提升至1.67，证明该组合自适应光学系统对板条MOPA固体激光器的复杂波前畸变具有极高的补偿效率。
3. **深层发现**：板条激光波前畸变具有强烈的空间各向异性（长边方向斜率远大于短边）。传统单2D DM的“全域均匀补偿”模式易导致驱动响应失配，而定向1D DM的引入实现了像差模态的物理分离，为同类高功率板条/切片激光器的光束质量控制提供了更优的工程范式。
