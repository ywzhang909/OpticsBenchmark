## 核心内容

### 背景与目标
- **研究背景**：自由空间光通信（FSOC）接收端受大气湍流影响会产生连续变化的波前像差，严重降低单模光纤耦合效率；传统基于图像的光斑优化方法实时性差，而监督深度学习虽精度高却极度依赖大量带标签（Zernike系数）的训练数据，难以落地。
- **本文目标**：提出物理深度学习（PDL）自监督相位恢复方法 → 通过将轻量化编码器与可微光学成像物理模型解耦结合，并利用输入与生成PSF的分布相似性构建损失函数 → 实现在无需先验标签的情况下实时、高精度地提取Zernike系数，满足FSOC场景对低延迟、强鲁棒性的工程需求。

### 研究内容
- **技术路线**：输入畸变光斑图像（PSF） → MobileNet V1编码器提取非线性特征 → 映射为隐藏层向量（Zernike系数组合） → 光学成像物理解码器（基于卷积成像方程与Zernike多项式相位展开）生成理论PSF → 计算输入与生成PSF的皮尔逊相关系数作为损失函数进行反向传播 → 推理阶段冻结解码器，仅输出Zernike系数用于波前校正。
- **关键方法**：
  1. **可微物理解码器自监督框架**：摒弃像素级监督，将光学衍射成像过程（`PSF = |FFT{P(u,v)}|²`，`P`含Zernike相位项）嵌入网络解码端。训练时通过“真实采集光斑 vs 物理模型重构光斑”的结构相似性驱动梯度更新，使网络隐式学习光场物理规律，彻底消除标注成本。
  2. **轻量化网络与相关系数损失设计**：选用MobileNet V1深度可分离卷积架构替代复杂UNet，大幅降低参数量与计算延迟；创新采用相关系数（Correlation Coefficient）替代传统MSE损失，使优化目标聚焦于光斑分布形态而非绝对像素值，显著提升含噪环境下的重建鲁棒性。

### 实验内容
- **数据**：
  - **仿真数据**：基于Zernike多项式生成。3~20阶模型训练集22,000张（D/r0=20）+ 20,000张离焦PSF；泛化测试集3,000张（D/r0=5~30）。3~64阶高阶测试集规模相当。图像尺寸256×256，像素尺寸5.5 μm。
  - **实测数据**：使用HoloEye LCSLM（型号pluto-2-NIR-011L，1920×1080分辨率，8 μm像素）加载相位板模拟湍流，532 nm激光源。CCD采集20,000张实验PSF用于训练，2,000张用于测试。数据预处理下采样至128×128。
- **实验设计**：
  - **仿真实验**：光学参数设定：瞳孔直径8.6 mm，透镜焦距150 mm，离焦量8 mm，波长532 nm。添加方差0.01的高斯白噪声模拟探测器噪声。使用MobileNet（batch size=32）训练，对比监督学习（MobileNet-Supervised）。分层评估3~20阶、3~64阶精度及跨D/r0泛化能力。
  - **实物实验**：光路结构：532 nm激光器 → 扩束准直器 → 分束器 → 偏振片 → 光阑(8.6 mm) → LCSLM → 成像透镜 → CCD(离焦8 mm)。采用NVIDIA Jetson TX2嵌入式平台进行TensorRT加速推理。输入实测光斑验证端到端实时性与Zernike系数提取一致性。
  - **复现结构提示**：`激光光源(532nm) → 准直扩束 → 光阑限束 → LCSLM调制相位 → 成像透镜 → CCD采集 → 下采样(256→128) → PDL编码器推理 → 输出Zernike系数`
- **实验结果**：

### 核心结论
1. **假设验证**：成功验证了“物理模型引导的自监督学习可替代全监督训练”的假设。PDL方法在无Zernike标签条件下实现了0.0648λ~0.1274λ的波前重建精度，仅比监督学习低约0.02λ，且完全规避了标注数据获取瓶颈。
2. **工程价值**：结合MobileNet轻量化架构与相关系数损失函数，该方法在Jetson TX2上实现3.72 ms/次的超低推理延迟，且对探测器噪声与不同D/r0湍流强度保持强鲁棒性，高度契合自由空间光通信实时像差补偿的实际需求。
3. **方法优势与局限**：自监督解码机制使模型具有优异的跨条件泛化能力，推理时无需物理解码模块，资源消耗与纯监督网络一致。但当前架构仅适用于点目标成像，且训练需预知光阑、焦距等系统参数，未来需扩展至多目标/变参数自适应场景。
