## 核心内容

### 背景与目标
- **研究背景**：传统哈特曼波前传感器在信标光能量不足或振幅分布不均匀（如子孔径缺光）时探测精度骤降；而无波前探测迭代算法收敛慢、实时性差，难以满足复杂动态环境下的近实时校正需求。
- **本文目标**：提出基于深度学习的远场光强反演波前相位方法 → 通过构建深度残差网络建立非线性直接映射机制 → 实现在缺光/弱光复杂条件下的高精度、近实时波前探测与静态像差闭环校正。

### 研究内容
- **技术路线**：输入远场光强图像 → 菲涅尔衍射角谱传输/双相机实验采集生成标签 → ResNet-50网络前向传播与特征提取 → 均方误差(MSE)损失函数优化 → 输出预测的Zernike多项式系数 → 重构近场相位并计算校正残差。
- **关键方法**：
    1. **基于ResNet-50的远场光强-波前非线性直接映射**：引入Shortcut残差连接解决深层网络梯度弥散问题，摒弃传统线性斜率反演与迭代重构，利用网络强大的特征拟合能力，将远场光斑图像直接前馈预测为近场Zernike系数，实现非迭代式快速相位反演。
    2. **双曝光融合动态范围增强数据采集策略**：针对缺光导致的光斑动态范围压缩问题，实验采用两台CMOS相机配合不同曝光时间同步采集，融合高低曝光图像扩展有效信号范围，提升训练数据在弱光/高对比度区域的特征完整性。

### 实验内容
- **数据**：
    - **仿真数据**：30,000组（29,000训练/1,000验证）。基于菲涅尔衍射角谱传输算法生成，随机抽取不同维度（15~66阶）Zernike多项式构建近场相位屏，计算对应256×256像素远场光强分布。
    - **实验数据**：30,000组（29,000训练/1,000验证）。实验室光学平台采集，LC-SLM生成PV值0.1λ~1λ的静态像差，哈特曼传感器测量真值Zernike系数，双CMOS记录远场光强分布。
- **实验设计**：
    - **仿真系统**：软件平台MXNet + Python。硬件：Intel i7-8700 CPU / NVIDIA GTX 2080 GPU。优化器Adam，初始学习率0.01，Batch Size=32，Epoch=40。输入256×256光强图，输出对应维度Zernike系数。
    - **实验光路组成**：650nm半导体激光器 → 滤波准直扩束 → 分光镜(BS1) → LC-SLM(1272×1024像元, 波长600-1100nm)引入相位像差 → 144单元MEMS变形镜反射 → 分光镜(BS2)分路 → ①高速哈特曼波前传感器(86fps, 准确率/40λ)测量真值；②双Photon focus MV1-D1312 CMOS相机(不同曝光时间, 分辨率1312×1082)采集远场图像。控制程序：Visual Studio 2015 C++。
    - **环境参数**：实验室常温静态环境，波长固定650nm，像差控制PV值0.1λ~1λ均匀分布，图像裁剪至256×256。
- **实验结果**：
    - **评估指标**：波前均方根(RMS畸变/RMS残差)、单帧预测时间(ms)、训练时间。
    - **基线对比**：隐含对比传统哈特曼传感器（缺光失效）与SPGD无波前迭代算法（收敛慢）。本文方法作为补充/初值估计。
    - **消融/影响因素设置**：Zernike维度(15-66)、噪声类型(高斯std=0.02/泊松)、湍流相位屏(模拟子孔径缺光)、训练数据量(5k-30k)、像差幅值范围。
    - **具体性能提升**：仿真基础组畸变RMS 0.1425λ → 残差RMS 0.0243λ（下降83%），预测1.53ms；实验组畸变RMS 0.52λ → 残差RMS 0.08λ（下降84.6%），预测1.67ms。受噪声/缺光影响残差仅微增至0.037λ/0.034λ，鲁棒性显著。

### 核心结论
1. **验证了核心假设**：深度学习（ResNet-50）能够成功建立远场光强分布与近场波前相位的非线性直接映射，在子孔径缺光、弱光或振幅不均匀的复杂条件下，仍具备高精度反演能力，有效弥补了传统哈特曼传感器的局限。
2. **实现了实时性突破**：单帧预测耗时仅约1.5~1.7ms（GPU加速），比传统无波前探测迭代算法快数个数量级，满足自适应光学系统对闭环控制实时性的严苛要求。
3. **明确了应用边界与规律**：未发现颠覆性意外，但明确了“高阶像差（维度>36）预测难度显著增加”及“残差RMS随像差幅值增大而递增”的规律。验证了该方法非常适合作为无波前传感系统的初始像差估计或闭环校正中的小像差精细补偿模块。
