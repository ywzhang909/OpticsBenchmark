## 核心内容

### 背景与目标
- **研究背景**：传统调制金字塔波前传感器（M-PWFS）需将倾斜镜置于入瞳共轭面，导致光学系统共轭面多、光路冗长、对准困难，且光束圆形调制易引发出瞳像偏移，制约了其在下一代大型天文望远镜自适应光学系统中的应用。
- **本文目标**：提出离散调制金字塔波前传感器（DM-PWFS）方法 → 通过将调制功能集成至反射微镜阵列（RMA）并利用焦平面中心点离散偏折模拟连续调制 → 实现光学共轭面减少、光路简化、出瞳像稳定及大动态范围/高带宽的波前高精度传感效果。

### 研究内容
- **技术路线**：入射波前光场 → 透镜组聚焦至RMA焦平面 → RMA按预设序列周期性离散偏折（中心点调制） → 分光至四象限探测器 → 采集四组出瞳光强(I1~I4) → 计算归一化差分信号(Sx, Sy) → 波前斜率解算与Zernike重构 → 驱动变形镜闭环校正。
- **关键方法**：
  1. **离散中心点调制机制**：摒弃传统M-PWFS在入射光路中调制光束的做法，改为利用RMA在焦平面执行多步离散偏折，模拟中心点在调制轨迹上的移动。光斑本身保持静止，仅等效中心点运动，从物理层面彻底消除了出瞳像偏移，大幅降低光机对准复杂度。
  2. **RMA参数优化与动态范围线性调控**：基于几何光学与泰勒展开推导，建立Sx/Sy与局部波前倾斜的线性映射关系。引入艾里斑半高全宽(FWHM)与微镜尺寸比值`k`作为核心设计变量，理论证明`k=1.5`时兼顾最优线性响应与最大动态范围；系统动态范围可通过离散调节调制半径（`n×Ms`）线性扩展，每增加1个微镜尺寸，动态范围扩大2倍线性常数（±0.2λ）。

### 实验内容
- **数据**：主要采用基于衍射理论与几何光学的**数值仿真数据**。数据集包含多阶Zernike像差模式（Z20, Z2-2, Z3-1, Z3-3, Z40等）及Kolmogorov湍流相位屏。初始波前RMS分别为0.88λ（Zernike组合）与0.64λ（Kolmogorov）。数据来源于MATLAB数值建模，无物理硬件实测（物理实验计划于2025年开展）。
- **实验设计**：
  - **实验环境/设备参数**：MATLAB 202X衍射仿真平台；RMA计算网格35×35（对应物理尺寸1μm/格）；入瞳直径7mm（传感）/4.2mm（闭环）；出瞳探测器分辨率120×200像素；波前校正器为21单元变形镜（假设无误差补偿）；透镜焦距经优化以匹配系统带宽。
  - **系统组成结构**：相位板/光源 → 聚焦透镜L1 → 反射微镜阵列(RMA) → 傅里叶透镜/棱镜分光模块 → 高速相机（四象限成像） → 信号处理与重构算法 → 21单元变形镜。光路仅保留入瞳与出瞳一个共轭面。
  - **复现指导**：按衍射理论构建光场传播模型，设置RMA离散偏折序列（如0、1、2、3×Ms半径对应的12/16步），按`S = (I1+I4)-(I2+I3) / (I1+I2+I3+I4)`计算输出，结合SVD逆矩阵法获取波前响应矩阵，驱动变形镜进行迭代闭环。
- **实验结果**：
  - **评估指标**：残差波前RMS值、焦平面Strehl Ratio (SR)、波前重构精度η（重构RMS/入射RMS）。
  - **基线与消融设置**：对比不同`k`值（0.5~2.5）对线性度与动态范围的影响；对比不同离散调制半径（0~3×Ms）下的传感范围；消融验证闭环迭代收敛性。
  - **性能提升**：`k=1.5`时实现最佳线性响应；调制半径3×Ms时动态范围达±0.7λ；Zernike闭环残差RMS降至0.00006λ（SR升至0.85）；Kolmogorov闭环残差RMS降至0.02λ（SR升至0.83），显著优于传统连续调制在出瞳偏移容忍度与光路紧凑性上的局限。

### 核心结论
1. **光路与对准简化**：DM-PWFS通过离散中心点调制机制替代传统入射光调制，显著减少了光学系统共轭面数量，消除了出瞳像偏移效应，大幅降低了光学设计复杂度与光机安装对准难度。
2. **动态范围与线性度优化**：理论模型与仿真证实，当艾里斑尺寸约为微镜尺寸的1.5倍（`k=1.5`）时，系统可在保持优异线性响应的前提下运行；通过离散调节调制半径，动态范围可按`±0.2λ/步`线性扩展，兼顾高灵敏度与宽范围传感。
3. **闭环校正性能验证**：自适应光学闭环仿真实验成功验证了DM-PWFS的工程可行性，针对标准Zernike像差与Kolmogorov相位屏，残差波前RMS分别降至0.00006λ与0.02λ，焦平面Strehl Ratio稳定在0.83~0.85，完全验证了初始假设，并展现出支持定制RMA、高调制频率（如60kHz）与未来空间/地基望远镜集成的巨大潜力。
