## 核心内容

### 背景与目标
- **研究背景**：传统波前传感技术（如夏克-哈特曼、剪切干涉仪）存在光能利用率低或空间分辨率受限等问题，而相位多样性（PD）方法虽光路简单且无私路像差，但因其高度依赖复杂的非线性迭代优化，计算耗时难以满足现代天文自适应光学系统毫秒甚至亚毫秒级的实时校正需求。
- **本文目标**：提出PD-CNN方法 → 通过融合焦点与离焦强度图像建立像素级到相位系数的非线性映射，并结合TensorRT优化推理引擎 → 实现无需迭代、亚毫秒级（约0.5 ms）且高精度的实时波前相位恢复效果。

### 研究内容
- **技术路线**：输入焦点与离焦强度图像（128×128双通道） → 卷积与最大池化特征提取 → PD-CNN轻量化网络处理 → TensorRT推理加速引擎优化 → 损失函数（MSE）反向传播与权重更新 → 输出前15阶Zernike系数（实际输出13个，剔除平移项）。
- **关键方法**：
  1. **PD-CNN轻量化网络架构**：基于LeNet-5改进，设计3层卷积、3层最大池化与2层全连接结构。直接接收归一化的双通道强度图像，摒弃传统PD算法的循环迭代与复杂先验假设，通过端到端回归直接预测Zernike系数，参数量少且易于硬件部署。
  2. **TensorRT推理加速技术**：将训练保存的Keras模型导入TensorRT 5.0，通过层融合、算子优化、GPU内核选择与内存布局调整，构建高性能推理引擎。在不显著降低精度的前提下，大幅提升前向传播吞吐率，实现毫秒至亚毫秒级延迟。

### 实验内容
- **数据**：共构建10,000对样本（训练集6000对，验证集1000对，测试集3000对）。输入为128×128的焦点与离焦强度图像对，像素值归一化至[0,1]；标签为对应大气湍流模拟（D/r₀=10）生成的Zernike系数。离焦像差峰值（PV）固定为1个波长（λ）。
- **实验设计**：
  - **光学系统组成**：光源（658 nm激光器+准直器+线偏振片） → 波前畸变模拟器（分束镜+SLM，像素15×15μm，512×512，PCIe 8-bit） → 传感器端（透镜组+相机Basler acA780-75gm，像素8.3×8.3μm，782×582，GigE 8-bit） → PD-CNN处理单元。相机分别置于焦平面与离焦面采集图像。
  - **计算平台与环境**：模型训练/测试在Intel Xeon E5-2609 v4 (1.7 GHz)、64 GB RAM、NVIDIA GTX 1080Ti (11 GB)上进行，使用Keras+Python 3.6.8（Adam优化器，初始学习率0.0001，Batch Size=32，Epoch=100）；推理加速实验在NVIDIA Jetson AGX Xavier嵌入式平台进行。
  - **对比/消融设置**：① 输入模态对比：仅焦点、仅离焦、焦点+离焦融合；② 模型对比：PD-CNN vs Xception；③ 平台对比：1080Ti vs Jetson Xavier；④ 加速前后对比：原始Keras推理 vs TensorRT加速推理。
- **实验结果**：
  | 实验类别/设计 | 数据与设置 | 核心结果 |
  |---|---|---|
  | **输入模态消融** | PD-CNN与Xception分别输入焦点/离焦/融合图像，测试集3000对 | 融合输入精度最高。PD-CNN融合模型MSE=0.0109（Xception为0.0139）；Estimated RMSE=0.0529λ，相对RMSE=0.1574 |
  | **推理时间对比(1080Ti)** | 3000对测试图像，Keras原始推理 vs TensorRT 5.0加速 | 融合模型原始推理2.56 ms → 加速后0.49 ms，加速比≈5.21倍，首次突破亚毫秒级 |
  | **推理时间对比(Xavier)** | 嵌入式平台，Keras原始推理 vs TensorRT 5.0加速 | 融合模型原始推理3.49 ms → 加速后1.26 ms，加速比≈2.76倍 |
  | **精度保留分析** | 加速后测试集相位恢复误差统计 | 融合模型加速后RMSE微升至0.0696λ，相对RMSE 0.2058，精度损失在可接受范围，仍优于单模态输入 |

### 核心结论
1. **验证了初始假设**：PD-CNN通过端到端学习焦/离焦强度图像到Zernike系数的非线性映射，成功替代了传统PD算法耗时的迭代过程，在保证高精度的同时实现了网络轻量化。
2. **融合机制显著提升性能**：焦点与离焦图像的特征融合有效缓解了单幅图像信息不足的病态逆问题，融合模型的测量误差（相对RMSE 0.1574）显著低于单模态输入，且推理速度优于同等条件的Xception基线。
3. **突破实时性瓶颈**：结合TensorRT引擎优化，PD-CNN在高性能GPU与嵌入式平台均可实现亚毫秒级（≤0.5 ms）预测，精度损失可控，完全满足现代自适应光学系统对波前传感与校正的实时性要求，具备工程落地潜力。未来可进一步扩展至16-bit高精度器件及65阶以上高阶像差恢复。
