## 核心内容

### 背景与目标
- **研究背景**：在空间光通信中，大气湍流会导致传输光束相位畸变与散焦，严重降低通信质量；传统单液晶空间光调制器(LC-SLM)自适应系统受限于液晶材料的偏振依赖性与色散效应，光能量利用率偏低。
- **本文目标**：提出基于双LC-SLM结构的无波前传感器自适应光学系统 → 通过正交偏振光互补调制与GS相位恢复算法闭环反馈 → 实现不同大气湍流强度下信号光束波前畸变的高效校正与光能量利用率提升。

### 研究内容
- **技术路线**：畸变光输入 → 偏振分束器正交分离 → LC-SLM1加载湍流相屏模拟扰动 → LC-SLM2加载GS算法反演的共轭相位图进行波前补偿 → 偏振合束器重组光束 → CCD采集远场强度分布 → PC端执行迭代反演与相位加载 → 输出校正后的收敛光斑。
- **关键方法**：
  1. **双LC-SLM正交偏振能量补偿机制**：针对单液晶调制器仅对特定偏振态有效的能量损耗瓶颈，利用偏振分束器将入射光分解为两束振动方向相互垂直的线偏振光，分别由两块LC-SLM独立进行纯相位调制，最后通过偏振合束器光路叠加。该设计充分利用了液晶分子对正交偏振态的独立折射率调控特性，使理论光能利用率接近理想状态。
  2. **基于GS算法的无波前传感器相位反演与共轭加载**：摒弃传统夏克-哈特曼等波前探测仪，直接采用Gerchberg-Saxton(GS)迭代优化算法。从CCD采集的远场光斑强度分布出发，通过300次正负菲涅耳衍射变换交替约束振幅与相位，逐步收敛至真实畸变相位，进而计算其空间共轭相位并转化为灰度映射图加载至LC-SLM，实现“强度检测→相位重构→共轭补偿”的无传感器闭环控制。

### 实验内容
- **数据**：
  - **仿真数据**：采用功率谱反演法生成大气湍流相屏（相屏宽度D=0.4 m，网格数128×128，光束波长λ=655 nm，高斯光腰半径w₀=20 mm，传输距离z=6 km，相屏间隔2 km），模拟强、中、弱三种湍流强度。
  - **实验数据**：使用波长650 nm单频激光光源，通过CCD相机记录校正前后的远场光斑图像，提取中心区域像素灰度值作为性能量化指标。

- **实验设计**：
  - **光路系统组成**：650 nm激光器 → 起偏器(P1/P2)调谐偏振态 → LC-SLM1(模拟湍流相位屏) → 偏振分束棱镜(PBS)将光束分为正交两路 → 双LC-SLM2/3独立加载共轭校正相位 → PBS偏振合束 → 中继透镜组(L1-L3)聚焦 → MV-EM系列CCD工业相机采集。
  - **核心设备参数**：
    | 设备型号 | 关键参数 |
    |---|---|
    | LC-SLM (Reallight RL-R2-SLM) | 靶面尺寸0.78″，像元12.3 μm，反射率>70%，刷新率60 Hz，工作波段400~700 nm，相位调制范围0~2π@532 nm |
    | CCD相机 (MV-EM系列) | 像素5.5 μm×5.5 μm，帧率8 fps，曝光时间300~1,000,000 μs，同步模式外触发/连续采集 |
  - **控制逻辑**：CCD图像实时传输至PC端 → GS算法迭代300次反演畸变相位 → 计算共轭相位并量化为0~255灰度图 → 驱动双LC-SLM同步加载 → 形成自适应校正闭环。

### 核心结论
1. **假设验证**：双LC-SLM架构结合GS算法的无传感器自适应系统能有效补偿大气湍流引起的波前畸变，校正后斯特列尔比(SR)在强、中、弱湍流下均大幅提升（最高达0.95），验证了该方案在复杂大气信道中的鲁棒性。
2. **意外发现**：正交偏振双通道调制不仅解决了液晶材料的偏振依赖损耗问题，还使校正后光斑中心光强提升超2倍以上，证明能量利用率优化可直接转化为远场聚焦能力的显著增强。
3. **工程意义**：摒弃传统波前传感器后，系统大幅降低了光学对准复杂度与硬件成本，为空间光通信接收端实现轻量化、高可靠性的动态波前补偿提供了可复现的理论模型与实验范式。
