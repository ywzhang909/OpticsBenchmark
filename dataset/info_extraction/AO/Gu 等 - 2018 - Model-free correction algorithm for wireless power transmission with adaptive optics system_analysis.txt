## 核心内容

### 背景与目标
- **研究背景**：激光无线电能传输（WPT）在大气中传输时，大气湍流会引起光束波前畸变与强闪烁，导致接收端光斑发散、能量密度骤降，严重制约传输效率与系统稳定性。
- **本文目标**：提出无波前传感器的自适应光学（Sensor-less AO）系统结合无模型优化算法 → 通过SPGD与PSO算法迭代计算形变镜（DM）驱动电压以补偿大气相位像差 → 实现光束能量在接收端高度聚焦，将WPT充电效率提升约37%。

### 研究内容
- **技术路线**：半导体激光源发射(808nm) → 倒开普勒望远镜扩束准直 → 模拟大气湍流引入随机相位畸变 → 32单元形变镜(DM)预补偿 → 分束镜分流（主光路至光伏板，旁路至CCD） → CCD捕获光斑能量分布图像 → 计算机提取性能指标（充电效率/斯特列尔比SR） → 调用无模型算法解算DM控制电压向量 → DM施加补偿相位 → 闭环迭代校正至光斑收敛 → 光伏板输出最大电功率。
- **关键方法**：
  1. **无波前传感器自适应光学架构**：摒弃传统夏克-哈特曼波前传感器，直接以接收端CCD采集的光强分布图像作为系统性能判据。结合形变镜驱动电压向量，通过“扰动-反馈-迭代”机制直接优化光斑能量集中度，降低系统复杂性与成本。
  2. **双算法对比校正机制**：重点对比随机并行梯度下降算法（SPGD）与粒子群优化算法（PSO）。SPGD通过随机扰动估计控制参数梯度实现并行优化；PSO作为群智能进化算法，利用个体历史最优(Pbest)与全局最优(Gbest)引导粒子搜索空间。论文详细推导了算法迭代公式，并分析了增益因子(γ)、扰动幅度(δ)、粒子规模及学习因子等关键参数对收敛速度与像差残余的影响。

### 实验内容
- **数据**：采用MATLAB数值仿真与实验室模拟光学链路。使用Zernike多项式(10/15/21/28/35阶)模拟不同强度的大气湍流随机波前相位畸变。初始引入8阶特定Zernike系数像差，基准斯特列尔比(SR)约40.58%，对应初始充电效率约40.58%。
- **实验设计**：
  - **系统组成**：半导体激光源(808nm) → 扩束准直系统 → 静态湍流相位屏 → 32单元形变镜(DM，驱动电极呈方阵排列，影响函数高斯近似) → 分束镜 → 工业CCD相机 → 图像采集卡与PC控制单元 → 负载光伏电池板。
  - **参数设置**：CCD像素尺寸与光伏板有效接收面积匹配；控制信号为32维电压向量。实验环境为实验室静态模拟。通过单变量法独立测试SPGD的γ/δ参数、PSO的粒子数(20/50/80/100/120)及初始电压敏感度(8组不同u0)。
- **实验结果**：
  - **评估指标**：充电效率 $\eta = P_m/P_{in}$，等价于斯特列尔比(SR)。
  - **基线与对比**：无校正基线效率约40.58%；对比算法SPGD与PSO。
  - **参数与消融结果**：SPGD在γ=1、δ=1时收敛最优（55次迭代达0.66）；PSO在粒子数≥80、η1=η2=2时表现最佳，收敛快且抗局部最优。PSO对不同初始电压向量几乎无敏感，校正稳定性显著优于SPGD。

| 实验组别/设计 | 数据与条件设置 | 结果与性能提升 |
|:---|:---|:---|
| **SPGD参数敏感性实验** | 固定扰动幅度δ=1，扫描增益因子γ(0.01~1) | γ=0.01收敛极慢(100次仅0.49)；γ=1时55次迭代达0.66，兼顾速度与校正能力 |

### 核心结论
1. **验证初始假设**：在无波前传感器的自适应光学系统架构下，通过无模型算法迭代控制形变镜，能有效补偿大气湍流引起的波前畸变，显著提升激光无线输电的能量聚焦度与传输效率。
2. **算法性能差异**：PSO算法在WPT波前校正中综合表现优于传统SPGD算法，具有更高的搜索精度、更快的收敛速度及更低的初值敏感性，平均充电效率提升约37%。
3. **关键影响因素**：算法内部参数（如SPGD的增益因子/扰动幅度、PSO的粒子群规模与学习因子）直接决定校正动态与最终像差残余水平，合理调参是实现高效、实时能量传输优化的核心前提。
