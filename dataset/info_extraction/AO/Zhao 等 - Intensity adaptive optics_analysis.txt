## 核心内容

### 背景与目标
- **研究背景**：自适应光学（AO）长期致力于校正相位与偏振像差，但光强像差（如瞳孔面强度分布不均、能量吸收/损失）广泛存在且会严重降低光学系统的分辨率与信噪比，然而现有的强度像差校正技术仍属空白。
- **本文目标**：提出强度自适应光学（I-AO）方法 → 通过构建“SLM偏振调制模块+变形镜”协同架构与双反馈控制机制 → 实现光强均匀性与系统总强度的同步校正，验证其在有传感器与无传感器模式下的可行性。

### 研究内容
- **技术路线**：激光光源 → 衰减片调节 → 强度像差引入 → SLM（夹于正交偏振片间）像素级调制 → 第一反馈环（S1：恢复瞳孔面强度均匀性） → 第二反馈环（S2：调节衰减片恢复总强度） → 变形镜（DM）补偿SLM引入的几何相位像差与残余相位误差 → 输出理想艾里斑焦斑与均匀光束。
- **关键方法**：
  1. **双反馈校正机制**：突破传统AO单环限制，将强度校正解耦为两个独立子任务。第一环路通过SLM直接测量/优化瞳孔面强度分布以恢复均匀性；第二环路基于参考数据独立调节光源后衰减片，补偿能量损失，确保校正过程不牺牲系统总光强。
  2. **强度泽尼克模式与无传感器间接优化算法**：针对强度非负的物理特性，设计非正交的强度泽尼克模式（Intensity Zernike modes）。在无传感器模式下，逐个扫描预设的15种强度模式及其系数，结合“焦斑图像低空间频率含量”与“焦斑圆度（Circularity）”双重图像质量指标，间接推断最优校正参数，同时利用DM同步补偿SLM调制伴生的附加相位误差。

### 实验内容
- **数据**：实验基于自建光学聚焦系统，未使用公开数据集。人为引入外部空间变化强度像差作为测试源；使用高分辨单色相机记录瞳孔面与焦平面的强度分布数据。
- **实验设计**（全部为真实光学实验，无仿真部分）：
  - **系统组成**：激光光源、可调衰减片（ND Filter）、反射式空间光调制器（SLM，8-bit灰度，正交偏振片夹持）、变形镜（DM）、成像透镜组、单色相机。SLM需预先通过逐像素扫描0-255灰度值建立强度响应查找表（LUT）进行校准。焦斑图像比例尺标定为30 μm。
  - **实验1（必要性验证）**：施加强度像差 → 仅开启传统相位AO（DM校正） → 记录焦斑仍畸变 → 移除强度像差 → 恢复衍射极限焦斑。对比各阶段焦斑截面强度曲线。
  - **实验2（基于传感器的I-AO）**：施加像差 → 传统相位AO预处理 → Loop S1（SLM调制恢复均匀性） → 相位AO → Loop S2（调节衰减片保总强度）。记录瞳孔面/焦平面强度图及截面曲线。
  - **实验3（无传感器的I-AO）**：施加像差 → 无传感器相位AO → 粗扫15个强度泽尼克模式（系数步进0.2）→ 按低空间频率与圆度指标选最优模式 → 应用校正 → 无传感器相位AO（残余相位）→ Loop SL2（恢复总强度）。记录各步骤焦斑演化。
- **实验结果**：
  - 实验1证实传统相位AO无法独立解决强度像差，必须引入I-AO才能恢复衍射极限聚焦。
  - 传感器模式下，I-AO双环校正后瞳孔面强度分布显著均匀化，焦斑截面强度峰值提升并紧密贴合理想艾里斑曲线。
  - 无传感器模式成功通过图像质量指标间接优化，恢复的焦斑形状与强度分布同样逼近理想状态，验证了算法在硬件受限系统中的有效性。

**实验设计与结果汇总**
| 实验组别 | 校正机制/关键步骤 | 核心观察指标 | 性能提升/结果 |
|:---|:---|:---|:---|
| **必要性验证** | 强度像差 → 仅相位AO(DM) → 移除像差 | 焦斑形状、截面强度分布 | 传统相位AO残留畸变；仅当强度像差移除后方可恢复理想艾里斑，证明I-AO不可替代性 |
| **传感器模式(I-AO)** | S1(SLM均匀化) → S2(衰减片总强度恢复) + DM相位补偿 | 瞳孔面强度分布、焦斑截面曲线 | 瞳孔强度均匀性显著提升，焦斑截面曲线峰值升高且包络逼近理论Airy分布 |
| **无传感器模式(I-AO)** | 扫描15个强度泽尼克模式(粗扫+精扫) → 低频/圆度指标筛选 → S2恢复总强度 | 焦斑图像圆度(C)、低空间频率含量、截面曲线 | 成功间接推断最优强度模式，焦斑形态与强度分布同步恢复，验证了无硬件传感器条件下的可行性 |

### 核心结论
1. **首次提出I-AO概念**：通过双反馈环路成功实现光强均匀性与总强度的同步校正，填补了自适应光学在强度像差校正领域的技术空白。
2. **双模态兼容性强**：I-AO同时支持基于传感器的直接瞳孔面测量与无传感器的焦斑图像间接优化，为紧凑型光学系统或无法加装强度传感器的应用提供了灵活方案。
3. **验证假设与应用潜力**：实验结果验证了初始假设（强度像差是限制高分辨聚焦的关键因素，且可被独立校正）。该技术可显著提升对绝对光强与分布均匀性要求苛刻的成像系统性能，在临床病理诊断（如视网膜OCT）、超分辨显微成像及天文观测等领域具有重要应用前景。
