## 核心内容

### 背景与目标
- **研究背景**：大气湍流引起的折射率微小起伏会导致激光波前发生严重相位与幅度畸变，干扰自由空间光通信与高功率激光传输。传统夏克-哈特曼(S-H)传感器在强湍流下易受光束破碎、闪烁及干涉效应影响，且受限于局部重建易产生“分支点”断裂，无法准确指导自适应光学系统。
- **本文目标**：提出改进型光场传感器重构方法 → 通过将其光学级联结构改造为微型开普勒望远镜阵列并匹配数值孔径，结合全局光线路径逆向追踪算法 → 实现湍流通道内激光波前相位（突破-π~π模糊限制）与幅度畸变的连续、高鲁棒性重建，为前畸变补偿与自适应光学提供精准指导。

### 研究内容
- **技术路线**：入射相干光场 → 物镜傅里叶变换分离角度信息 → 微透镜阵列(MLA)匹配焦面与NA分布空间信息 → CCD记录4D光场分块图像 → 基于参考分块与“渐晕”效应微调光线的逆向路径追踪 → 相位梯度计算与环路连续性滤波 → 输出重建波前/相位屏及幅度分布。
- **关键方法**：
  1. **硬件架构创新**：将传统光场相机重构为“共享物镜的微型开普勒望远镜阵列”。精确级联物镜后焦面与MLA前焦面，确保 `NA_objective ≥ NA_MLA`。利用微透镜边缘的渐晕(Vignetting)效应建立子图像间的坐标映射，使每个传感器像素直接编码一条光线的空间位置与角度，实现4D光场到2D图像的高效无损压缩。
  2. **算法机制创新**：提出“全局光线逆向追踪与相位梯度积分算法”。摒弃传统S-H传感器的局部质心检测，该算法通过选取高亮参考分块、构建向量基线、逆推光线至最佳聚焦深度平面、提取X/Y方向相位梯度，并利用“连续相位环路梯度积分为零”的物理约束进行滤波。具备三大应用模式：单相位屏重建、无参考光智能干涉仪测量、多相位屏3D通道分解。

### 实验内容
- **数据**：使用OKO压电变形镜（37个致动器，直径30mm）生成已知Zernike多项式相位畸变；输入为波长632.8nm的准直高斯激光束；像元尺寸5.5μm，分辨率1024×1024。
- **实验设计**：
  - **系统设备**：激光源 → 37致动器变形镜 → 光场传感器（物镜f=750mm, D=2inch；MLA 10×10mm, 间距300μm, EF=5.1mm；Allied Vision GX1050 CCD, 109fps） → 数据处理工作站。
  - **环境/参数**：实验室光学平台，室温稳定；变形镜驱动命令范围0~4095（对应0~150V，最大形变5.5λ）；重构深度通过逆向追踪使光斑恢复高斯分布自动优化；控制闭环总耗时约13ms。
- **实验结果**：以重建致动器通道值与原始驱动命令的相关系数(Correlation)、均方根误差(RMS Error)为核心指标。重建结果普遍优于S-H传感器，最大畸变处的绝对误差多控制在λ/2以内。

| 实验设计 | 数据/设备配置 | 结果与性能指标 |
|:---|:---|:---|
| **单屏-离焦畸变** `[Z(2,0)]` | 变形镜施加5.5λ最大离焦，中心参考分块法 | 相关系数 `0.956`，RMS误差 `0.59λ`，验证对称梯度映射有效性 |
| **单屏-基础Zernike模式** `[Z(1,1)~Z(4,4)]` | 分别施加倾斜、像散、三叶草、四叶草畸变 | 相关系数 `0.842~0.993`，RMS误差 `0.20λ~0.62λ`（平均占最大畸变10%），边缘致动器误差略大（积分累积效应） |
| **单屏-复合畸变** `[Z(3,3)+Z(4,4)]/2` | 两种模式各半叠加 | 相关系数 `0.917`，RMS误差 `0.54λ`，证明任意复合畸变可线性叠加重建 |
| **双屏-多相位屏重建** | 变形镜 + 光路中插入随机玻璃板 | 两屏重建相关系数 `0.8042` 与 `0.8141`，RMS误差 `0.85λ`，验证单图像可反演3D分布，但误差相互耦合传递 |

| **系统实时性测试** | CCD采集+CPU算法+致动器设置 | 闭环周期 `~13ms`（采集9.2ms+处理3.1ms+设置≈1ms），单屏算法支持并行加速潜力 |

### 核心结论
1. **理论验证**：成功验证了光场传感器在复振幅提取中的物理机制，突破了传统干涉仪相位解调的`(-π, π)`模糊限制，可实现最高多倍`2π`的连续相位与幅度同步重建。
2. **性能优势**：全局光线路径逆向追踪算法显著增强了波前重建的鲁棒性，有效规避了强湍流下的分支点问题与低照度干扰，重建相关系数普遍>0.9，为自适应光学前畸变补偿提供了高精度、低延迟的解。
3. **意外发现与局限**：实验意外证实单幅光场图像可反演湍流通道内的多相位屏3D结构，但多屏重建误差具有相互传递性；单屏重建算法具有高度线性可并行性，而多屏算法需进一步解耦优化以兼顾效率与精度。
