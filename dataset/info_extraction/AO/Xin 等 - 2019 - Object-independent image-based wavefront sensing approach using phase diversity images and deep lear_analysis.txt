### 核心内容

#### 背景与目标
- **研究背景**：传统深度学习像面波前传感方法多局限于点光源，或需生成海量扩展场景数据进行训练，难以适应未知物体的实际成像场景；且相位像差会严重限制非相干成像系统的分辨率。
- **本文目标**：提出一种目标无关的频域特征提取与深度LSTM网络融合方法 → 通过两幅已知离焦差异的像平面的频域自相关运算消去物体信息，提取仅由相位像差决定的特征序列 → 实现无需扩展场景训练即可高精度恢复任意点源/扩展场景的波前相位。

#### 研究内容
- **技术路线**：输入一对已知离焦差异的在焦/离焦像 → 傅里叶变换与自相关运算提取频域目标无关特征图像 → 将特征图按行/块分解为输入序列 → 序列输入128层深度LSTM网络进行空间依赖学习 → LSTM输出序列拼接为向量输入全连接层 → 输出2~N阶Fringe Zernike像差系数 → 系数输入去卷积模块完成高分辨率图像重建。
- **关键方法**：
  1. **频域目标无关特征提取机制**：利用两幅像平面的光学传递函数比值在频域消去未知物体频谱，构造仅与复瞳孔函数(即相位像差)相关的自相关特征图像。从数学模型上切断网络对特定物体分布的依赖，使训练数据可完全由模拟PSF生成。
  2. **深度LSTM非线性映射网络**：将空间特征图转化为序列输入，利用LSTM的门控记忆单元捕捉像素间的长程空间依赖关系，替代传统CNN的卷积操作。该设计解决了当前像差恢复问题中特征呈稀疏散点分布、CNN卷积提取困难且易饱和的瓶颈。

#### 实验内容
- **数据**：
  - **仿真数据集**：10000组随机生成的2~9阶/2~21阶/2~37阶Fringe Zernike像差系数及对应PSF图像。
  - **实验数据集**：使用632.8nm He-Ne激光经半透明散射介质(牛奶溶液)产生的扩展光源(分辨率板)，采集光学系统不同视场(对应不同像差分布)的在焦/离焦图像。
- **实验设计**：
  - **仿真端**：光学参数(孔径11.5mm/焦距150mm/波长632.8nm/像元5.5μm/离焦量1mm)。网络架构为128层LSTM+全连接，采用Adam优化器(lr=1e-4, batch=10, epoch=40, dropout=0.2)，注入50dB高斯噪声与±0.1mm离焦误差。纯CPU环境(Intel Core i7-6700/16GB RAM)训练约4小时，无GPU依赖。
  - **实验端**：单透镜成像光路系统。激光器→散射物→扩展孔(分辨率板)→单透镜→CCD探测器。探测器置于共轭面，通过精密位移台微调引入已知离焦。所有光机参数与仿真严格一致，采集多组不同视场扩展像进行像差恢复与去卷积重建。
  - **对比/消融设计**：① 传统相位差(Phase Diversity)全局优化算法对比；② 深度LSTM vs ResNet 18(CNN)在2~9阶/2~21阶像差恢复下的精度与耗时对比；③ 入射光光谱带宽(5~600nm)对相干训练模型泛化误差影响的定量分析。
- **实验结果**：
  - **仿真精度**：网络训练/测试集像差恢复绝对误差均值分别为1.51×10⁻⁴λ与1.67×10⁻⁴λ；应用于未知扩展场景时恢复像差均方误差为2.3×10⁻³λ，重建图像分辨率显著恢复。
  - **基线对比**：传统相位差算法与LSTM结果均方绝对误差为8.7×10⁻³λ，高度吻合。LSTM在2~9阶测试误差为1.67×10⁻⁴λ，ResNet 18高达1.14×10⁻²λ；阶数增至21阶时，LSTM误差仅微增至2.96×10⁻⁴λ，而ResNet 18恶化至6.34×10⁻²λ。LSTM单次推理耗时仅0.35ms，推理效率远超CNN。
  - **光照容限**：光谱带宽<150nm时恢复精度几乎不受影响；带宽>150nm后误差随带宽增加，且误差增大程度主要受像差系数范围影响，与恢复阶数关系较弱。

#### 核心结论
1. **目标无关性成功验证**：频域特征提取从数学根源解耦了物体信息与相位像差，网络无需任何扩展场景数据训练，即可高精度泛化至任意未知点源或扩展目标的波前传感，突破了现有深度学习波前传感对训练物体类型的限制。
2. **LSTM在非线性像差拟合中优势显著**：深度LSTM凭借序列记忆能力，在拟合精度(比ResNet 18低1~2个数量级)和计算效率(单帧推理0.35ms)上全面优于传统CNN，且对输出像差阶数增加不敏感，极适合动态高速波前探测场景。
3. **低门槛与明确工程容限**：该方法仅依赖普通CPU即可高效训练与推理，大幅降低算力门槛；入射光非相干性影响具有明确阈值(带宽<150nm可忽略)，为实际应用中的光学滤波设计提供了定量依据。
