## 核心内容

### 背景与目标
- **研究背景**：传统相位恢复波前传感方法依赖迭代优化，计算耗时且易受初始值影响陷入停滞；现有基于像素或CNN的神经网络方法结构复杂、训练困难或实际精度不足，且缺乏真实环境验证。
- **本文目标**：提出基于特征的相位恢复波前传感方法 → 通过引入离散正交Tchebichef矩提取离焦/离焦平面PSF几何特征，并利用反传BP神经网络建立特征与像差系数的非线性映射 → 实现无需迭代优化、计算负荷低、高效率且高鲁棒性的光学系统像差直接重建。

### 研究内容
- **技术路线**：输入（离焦/离焦平面PSF图像对） → 预处理（去噪、强度归一化、亚像素配准消除Tip-Tilt影响） → Tchebichef矩特征提取（数据压缩） → 反传人工神经网络（非线性拟合） → 输出（Zernike像差系数）。
- **关键方法**：
  1. **Tchebichef矩特征提取**：利用在离散图像坐标空间严格正交的Tchebichef多项式基计算低阶矩。该方法无需连续积分近似与坐标变换，能高效表征PSF强度分布，将高维图像数据压缩为一维特征向量，大幅降低网络输入维度。
  2. **反传人工神经网络（BP ANN）非线性映射**：构建浅层BP网络（输入层-隐藏层-输出层），采用监督学习与梯度下降法训练权重。训练完成后网络可直接输出像差系数，彻底规避了传统相位恢复算法的迭代停滞问题，且相比深层CNN更易训练、硬件负载更低。

### 实验内容
- **数据**：
  - **模拟数据**：10万组随机生成的4th~9th阶Fringe Zernike像差系数，依据傅里叶光学生成对应PSF图像对，并叠加50dB高斯噪声与±0.1mm离焦距离误差。划分为训练集(40%)、验证集(30%)、测试集(30%)。
  - **真实数据**：单透镜光学系统实际采集的20对离焦/离焦平面PSF图像。
- **实验设计**（含复现参数）：
  - **光学系统**：焦距180mm，光圈直径8.5mm，离焦距离2mm，工作波长0.6328μm，探测器像元尺寸5.5μm。
  - **参考仪器**：PhaseCam 4020干涉仪（用于直接测量波前并作为真值参考）。
  - **流程**：① 生成模拟数据集并提取Tchebichef矩；② 使用Matlab NN Tool训练BP网络（隐藏层30节点）；③ 采集实测PSF，经预处理提取特征后输入网络重建像差；④ 定性对比重建像差再生PSF与实测PSF，定量对比干涉仪测量值。
  - **复现指导**：需精确标定光学系统参数；预处理必须包含强度归一化与消除质心漂移的亚像素平移；网络建议采用浅层BP结构（隐藏层20-50节点），激活函数可选Sigmoid，优化器用梯度下降或Levenberg-Marquardt。

### 核心结论
1. **方法有效性验证**：提出的基于Tchebichef矩与BP网络的特征恢复方法成功将波前传感转化为非线性拟合问题，无需迭代即可直接输出高精度像差系数，实验验证其在真实光学环境中平均误差为0.031 waves，具有高效率、高鲁棒性与低计算负荷优势。
2. **捕获范围与精度矛盾**：揭示了神经网络训练区间（捕获范围）与拟合精度之间的权衡关系：扩大训练范围可增强抗干扰能力但牺牲精度，缩小范围可显著提升精度但限制适用范围。
3. **潜在应用路径**：网络精度略低于传统迭代方法但在工程应用中完全可接受；提出将其作为传统迭代算法的“优质初始值提供器”，并建议采用“粗分类+精拟合”双网络架构以突破范围-精度矛盾，为后续研究指明方向。
