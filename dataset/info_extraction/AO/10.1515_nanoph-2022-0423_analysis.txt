## 核心内容

### 背景与目标
- **研究背景**：深度学习对算力的需求呈指数级增长，模拟光子计算凭借超高带宽、小体积与低功耗优势成为突破“数字能耗墙”的关键路径。然而，光子芯片物理尺寸受限及高速光电组件的位精度瓶颈，导致其难以直接媲美数字处理器，且链路过噪声严重制约了推理精度。
- **本文目标**：提出基于硅光子处理器与时分复用(TDM)的分块矩阵乘法及动态精度推理方法 → 通过建立光子链路噪声系数与网络各层位精度需求的解析模型，并结合标签平滑训练策略动态分配各层计算速率 → 实现无需重新训练即可在维持分类精度同时，将线性操作执行时间缩短55%的速效推理效果。

### 研究内容
- **技术路线**：输入(IRIS数据集样本) → 数字电域量化与AWG波形生成 → 硅基相干光子交叉矩阵(2:1 EAM调制器)进行光域权重与输入编码 → TDM架构执行分块矩阵乘法(TMM) → 理论NEQB模型指导各层动态速率调节 → 光电信号转换(PD+RTO)与软件域Sigmoid激活 → 输出分类结果。
- **关键方法**：
  1. **光子链路噪声等效量化位(NEQB)解析模型**：系统建模了激光相对强度噪声(RIN)、散粒噪声、ADC量化噪声、热噪声及矩阵乘法噪声，推导了带宽与NEQB的定量关系公式。模型揭示了插入损耗(NIL)与计算速率对精度的耦合影响机制，为硬件速率选择提供理论边界。
  2. **硬件感知动态精度推理机制**：针对神经网络各层对精度敏感度不同的特性，在预训练网络后阶段引入动态速率调度。根据NEQB模型与各层容忍阈值，为高噪声容忍层分配高速率(50 GHz)，为敏感输出层分配低速率(2 GHz)，在硬件后置推理阶段实现精度-速度的自适应平衡。

### 实验内容
- **数据**：IRIS数据集（原始30个样本，实验重复加载15次共450个样本用于统计评估）。用于3分类问题，网络拓扑为4输入:10隐藏:3输出的全连接层。
- **实验设计**：
  - **光学系统**：1560 nm激光器(CoBrite-DX) → 光栅耦合器(IL=3 dB)注入硅光子芯片(SiPho) → MZI干涉臂内嵌两个级联EAM调制器(单模块IL=4.4 dB)编码输入/权重 → 热光相移器(TOP)静态偏置 → 3 dB MMI相干叠加 → PIN光电探测器(响应度0.12 A/W, 带宽50 GHz)。芯片总插入损耗约15 dB。
  - **电域/软件系统**：Keysight M8194a 4通道AWG提供DAC输入 → DSP栈执行量化/滤波/重采样/时钟恢复 → Keysight DSOZ632a 实时示波器捕获模拟输出 → 软件域实现Sigmoid激活函数与分类逻辑。
  - **训练配置**：AdamW优化器，学习率0.01，Batch size 32，80 epochs。采用标签平滑训练应对正权重重约束。
  - **实验分组**：① 固定精度推理（全层统一运行于最低容错速率）；② 动态精度推理（首层50 Gbaud，输出层分别测试2/16/50 Gbaud）；③ 消融实验（独立量化各层NEQB位宽1-8 bit，观测精度衰减阈值）。
- **实验结果**：主要评估指标为分类准确率、执行时间、NEQB阈值。基线为固定速率方案。消融实验验证了各层精度容忍度差异。具体性能：软件基线准确率96.6%。动态推理首层50 GHz准确率达96.6%；输出层在2 GHz/16 GHz/50 GHz下准确率分别为93.1%/86.4%/68.6%。动态推理相比固定精度方案执行时间降低55%，精度损失<1%。

### 核心结论
1. **验证了动态精度推理的工程可行性**：通过TDM分块矩阵乘法与NEQB理论模型指导的速率动态调度，在预训练网络后置推理阶段成功实现精度-速度优化，相比固定精度方案执行时间缩短55%，且未引入显著精度损失，验证了初始假设。
2. **揭示了光子硬件噪声与网络拓扑的映射规律**：神经网络不同层对光子链路噪声的容忍度存在显著差异（首层高度容忍，输出层敏感），证实了“硬件感知型动态精度”是突破模拟光子计算精度瓶颈的有效途径。
3. **存在模型与实验的偏差及意外发现**：理论模型基于加性高斯白噪声(AWGN)假设，但在高速率(接近器件带宽极限)下，确定性噪声（如光电组件有限带宽引起的码间干扰）占比上升，导致实验精度衰减快于理论预测。这一发现提示未来光子神经网络加速器的设计需引入确定性噪声补偿机制或自适应均衡算法。
