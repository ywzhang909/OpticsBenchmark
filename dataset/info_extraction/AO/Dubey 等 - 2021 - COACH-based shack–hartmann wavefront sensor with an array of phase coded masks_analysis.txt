## 核心内容

### 背景与目标
- **研究背景**：传统夏克-哈特曼波前传感器（SHWS）的测量精度和灵敏度受限于微透镜阵列产生的焦点光斑尺寸，光斑越宽导致局部波前斜率估计误差越大，制约了高精度波前探测的应用。
- **本文目标**：提出基于编码孔径相关全息（COACH）技术的SHWS改进方法 → 通过引入编码相位掩模（CPM）阵列替代传统微透镜，并结合非线性互相关（NCC）算法生成极窄的互相关峰值 → 实现局部波前斜率测量精度的显著提升，使整体波前重建均方误差（MSE）降低一个数量级。

### 研究内容
- **技术路线**：输入待测波前（经相位物体调制） → 空间分割为M×N个子孔径 → 每个子孔径透过CPM与微透镜组合结构 → 光场经傅里叶变换在相机平面形成稀疏随机点阵 → 参考点阵与测量点阵进行非线性互相关（NCC）运算 → 提取相关峰值位移量计算局部倾斜角 → 区域重建算法融合所有局部斜率 → 输出完整三维波前重建结果。
- **关键方法**：
    1. **CPM合成与稀疏点阵生成**：采用改进的Gerchberg-Saxton (GSA)算法合成具有混沌相位分布的编码相位掩模，使其在傅里叶面产生稀疏、随机分布的强度光点阵列。该结构突破了传统微透镜焦点的尺寸限制，为高精度位移检测提供基础。
    2. **非线性互相关（NCC）与双极降噪**：提出引入参数α和β的非线性互相关算法替代传统线性相关，通过最小化重建均方误差（MSE）自适应优化参数以压缩相关峰值宽度；进一步引入双极（bipolar）点阵模式（两次独立CPM曝光后强度相减），有效抑制背景噪声与串扰，使相关峰值更加锐利，大幅提升斜率测量灵敏度。

### 实验内容
- **数据**：使用数字模拟波前作为真值/参考基准。通过MATLAB以与实验光路完全相同的参数（光源波长、传播距离、孔径尺寸等）进行数值Fresnel传播生成，模拟一个焦距30cm的正透镜产生的已知波前。
- **实验设计**（含仿真与真实实验系统结构，可供复现）：
    - **仿真/基准数据**：MATLAB数值Fresnel传播生成数字波前。
    - **真实实验系统结构**：HeNe激光器(8mm光束) → 扩束镜组(f1=10cm, f2=48cm) → 20μm针孔(低通滤波生成平面波) → 相位物体(30cm正透镜) → 空间光调制器(SLM) → 分束器(Beamsplitter) → 光学中继系统 → CMOS相机。光路各物理距离参数见原文图1(b)（单位cm）。
    - **核心设备参数**：
        - SLM：Holoeye PLUTO，1920×1080像素，8μm像元间距。中央1020×1020像素区域显示30×30阵列，每个单元34×34像素。
        - 相机：PCO.Edge 5.5 CMOS，2560×2160像素，6.5μm像元间距。
        - 光学中继：将微透镜阵列焦面准确成像至相机靶面。
    - **实验变量设置**：
        - 基线对比：常规SHWS（SLM仅显示f=6.5mm微透镜阵列） vs 本文COACH-SHWS。
        - 编码参数：稀疏点阵数量(3, 5, 10, 12)。
        - 相关模式：单极(Unipolar, 单次曝光) vs 双极(Bipolar, 两次曝光相减)。
        - 算法参数：NCC优化参数组 [(α=0.0, β=1.0)] vs [(α=0.1, β=0.9)]。
        - 重建区域：全局1020×1020像素 vs 中心裁剪800×800像素。
    - **环境参数**：标准光学实验室环境（常温常压，暗室防振光学平台，文中未特别强调特殊温湿度控制）。

### 核心结论
1. **方法验证**：提出并实验验证了基于COACH架构的SHWS新方法，成功利用CPM阵列与NCC算法生成极窄相关峰值，从根本上突破了传统微透镜焦点尺寸对斜率测量精度的限制。
2. **假设验证**：实验数据确凿验证了“相关峰值越锐利，局部斜率测量与整体波前重建精度越高”的初始假设。最优方案（3点双极模式，MSE=0.00045）使重建误差较常规SHWS降低一个数量级。
3. **权衡与拓展**：存在明确的“精度-速度”权衡。双极模式精度最高但需两次曝光；若对实时性要求更高，单极5点阵模式可在单次曝光下实现常规SHWS约2倍的精度。未出现意外发现，但证实了稀疏点数并非越多越好（5点最优，过多反而因信息冗余/计算复杂度导致性能波动），为不同应用场景提供了可配置的工程指南。
