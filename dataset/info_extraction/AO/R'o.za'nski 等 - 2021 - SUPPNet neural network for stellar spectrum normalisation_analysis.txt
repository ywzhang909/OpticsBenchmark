## 核心内容

### 背景与目标
- **研究背景**：恒星光谱精确的连续谱归一化是后续精细光谱分析（如元素丰度测量、大气参数反演）的必需预处理步骤。传统方法（多项式拟合、频率域滤波、凸包理论等）严重依赖人工参数调节，且在处理宽吸收线、强发射线及合并阶跃光谱(échelle spectra)的残余波纹时易产生系统性偏差，效率低且不可复现。
- **本文目标**：提出**SUPPNet全卷积深度神经网络方法** → **通过双层金字塔池化模块(UPPNet)联合分段与回归任务、滑动窗口加权平均及平滑样条后处理机制** → **实现高精度、全自动且支持灵活人工微调的恒星光谱伪连续谱提取**。

### 研究内容
- **技术路线**：原始光谱输入 → 重采样至0.05 Å/像元 → 滑动窗口(长度8192，步长256)分割 → Min-Max归一化 → **SUPPNet主干**(双层UPPNet提取多尺度上下文特征) → 双任务预测头输出伪连续谱与分段掩码 → 滑动平均融合与不确定性估计 → 反归一化 → SciPy平滑样条拟合(自适应节点调整) → 输出标准化光谱与误差带。
- **关键方法**：
  1. **SUPPNet架构设计**：基于U-Net改进，核心创新为用**金字塔池化模块(PPM)**替代传统跳跃连接，结合**堆叠架构**(Stacked UPPNet)与**深度监督**(Deep Supervision)。网络包含4个预测头(Seg 1/2, Cont 1/2)，通过联合优化一维谱线分段与伪连续谱回归，有效捕捉全局背景趋势与局部复杂谱线结构，缓解梯度消失并提升特征表征能力。
  2. **主动学习数据扩充策略**：采用两阶段训练。首先利用15万条参数随机生成的合成光谱（覆盖O-G型恒星、不同旋转/湍流展宽及仪器分辨率R=40k~120k）进行预训练；随后用预训练模型自动处理真实观测光谱，经天文学家逐条手动精细校正后构建约250条高质量观测数据集作为主动学习数据。该方法有效矫正了纯合成数据带来的分布偏差，显著提升模型对真实观测噪声及发射谱线的泛化能力。

### 实验内容
- **数据**：
  - **合成数据集**：150,000条，基于SYNTHE/ATLAS与BSTAR/OSTAR模型生成，覆盖Teff 3000–55000 K，log g 1.0–5.5，加入物理合理的旋转/微湍流卷积、仪器响应及高斯噪声(S/N 30–500)。
  - **主动学习/观测数据集**：约250条，源自UVES POP项目(ESO, R=80,000)与FEROS项目(ESO La Silla, R=48,000, S/N>500)，经专家手动校正。
  - **测试集**：100条UVES POP实测光谱(O–G型)；6颗典型恒星(HD 155806, 90882, 27411, 37495, 59967, 25069)用于精细化对比。

- **实验设计**（含复现参数）：
  1. **仿真预训练实验**：数据增强(随机裁剪0.7–2.5倍率、Y轴50%翻转、高斯噪声) → 重采样0.05 Å → 滑动窗口8192样本 → 输入网络 → Nadam优化器(初始lr=1e-4，100 epoch后降至1e-5，batch size=128) → 损失函数：MSE(连续谱预测，权重×400) + BCE(分段) → 训练150 epoch。
  2. **主动学习微调实验**：加载预训练权重 → 10%合成数据替换为250条专家校正观测数据 → 相同增强与优化设置 → 继续训练100 epoch → 输出`SUPPNet(active)`。
  3. **真实光谱处理实验**：输入光谱重采样至0.05 Å → 滑动窗口预测(每像元被预测32次) → 权重平均融合 → 反归一化 → 调用`SciPy UnivariateSpline`平滑(输入模型预测的不确定性以控制样条节点密度) → 基线对比：3位专家使用`HANDY`工具独立手动拟合。
  4. **鲁棒性控制变量实验**：固定HD 27411光谱参数 → 独立改变S/N(30, 500)、仪器分辨率(10⁴, 10⁵)、投影自转速度vsin i(0, 50, 100, 200 km/s) → 记录伪连续谱预测残差统计。

- **实验结果**：

| 实验类别 | 数据与设置 | 基线/对比方法 | 主要指标与结果 | 性能提升/发现 |
|:---|:---|:---|:---|:---|
| **合成谱归一化测试** | 1200条合成谱(6星×200种伪连续谱扰动) | `SUPPNet(synth)` vs `SUPPNet(active)` | Active版残差离散度(15.87~84.13分位差)普遍略低；<4500Å区系统偏差约-0.01 | 主动学习有效修正合成数据导致的伪连续谱系统性下偏，提升宽氢线区拟合准确性。 |

### 核心结论
1. **验证了初始假设**：SUPPNet实现的全自动光谱归一化精度(3900–7000 Å RMS=0.0128)与经验丰富的天文学家手动拟合高度一致，且彻底消除了人工操作的主观偏差与不可复现问题，特别适用于大规模巡天光谱的标准化处理。
2. **主动学习显著突破合成数据局限**：纯合成数据预训练模型在<4500 Å及宽吸收线区存在系统性下偏；引入约250条专家手动校正的真实光谱进行主动学习微调后，有效对齐了人类专家的光谱先验认知，并大幅提升了对实际仪器波纹、发射谱线及观测噪声的鲁棒性。
3. **意外发现与泛化价值**：G型及更晚型恒星因连续谱本身被大量窄线严重遮蔽，模型倾向于将伪连续谱置于实际物理连续谱下方（与人类习惯相反）。此外，SUPPNet核心架构与平滑样条后处理机制不依赖特定天体先验，可直接迁移至拉曼光谱、地学信号处理等任意需要背景建模或趋势移除的一维科学数据场景。
