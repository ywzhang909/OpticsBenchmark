## 核心内容

### 背景与目标
- **研究背景**：地基极大望远镜直接成像探测宜居系外行星需依赖极端自适应光学（XAO）系统，以千赫兹速率控制数千致动器。然而，传统积分器控制法受限于系统测量与控制延迟误差及光学配准误差，导致恒星边缘（系外行星主要分布区）残留大量准静态斑点光通量，严重制约高对比度成像的科学目标达成。
- **本文目标**：提出PO4AO（基于模型的强化学习策略优化）方法 → 通过学习环境动力学模型并端到端反向传播优化控制策略网络 → 实现抗延迟、抗配准误差与快速推理的极端自适应光学闭环控制，显著降低冕谱仪点扩散函数的残余光通量。

### 研究内容
- **技术路线**：输入历史波前传感器测量与致动器电压指令(构建部分可观测马尔可夫状态) → 全卷积神经网络提取时空特征并预测下一帧观测值(训练动力学模型) → 基于集成动力学模型模拟长步长控制轨迹，利用可微奖励函数直接反向传播优化策略网络参数 → 将策略输出投影至Karhunen-Loève(KL)可控模态空间 → 输出致动器控制电压完成闭环校正。
- **关键方法**：
    1. **PO4AO模型基策略优化算法**：融合模型强化学习的采样效率与有模型学习的规划能力。算法先运行策略收集真实交互数据，训练基于CNN的动力学模型预测系统下一状态；随后利用该模型采样多条状态-动作轨迹，通过可微的残差能量奖励函数进行端到端梯度反向传播，直接优化策略网络。该方法克服了无模型RL在数千自由度控制空间采样困难、以及传统有模型RL规划计算过慢的瓶颈。
    2. **空间卷积架构与KL模态投影机制**：针对AO系统致动器与波前传感器网格化空间分布特性，采用全卷积神经网络（Fully CNN）天然捕获空间相关性，大幅提升特征提取效率与推理速度。策略输出层引入KL正交基投影滤波，强制控制指令落入物理可控子空间，彻底滤除波前传感器不可观测的模态（如波浪模态和边界致动器），保障闭环稳定性。

### 实验内容
- **数据**：
    1. **数值模拟数据**：使用COMPASS天文光学仿真包生成。包含8-m望远镜(VLT规模，1364致动器)与40-m望远镜(ELT规模，10556致动器)。大气模型为3层von Karman湍流（$r_0$=16 cm @ 500 nm），波前传感器采用非调制金字塔WFS(PWFS)。
    2. **实验室真实数据**：MagAO-X极端自适应光学实验系统（woofer-tweeter双镜架构）。通过光学平台注入单层模拟冻结流湍流扰动（$r_0$=16 cm @ 500 nm，风速5/15/30 m/s对应1 kHz等效速率），实际系统受限于CPU-GPU数据交换，闭环运行频率为100 Hz。
- **实验设计**：
    1. **VLT规模仿真对比**：在0等星（低噪声）与9等星（高光子噪声）环境下，运行PO4AO（初始5000帧积分器预热，共训练约3万帧）与经典积分器控制器，记录Strehl比、奖励值与RAW PSF对比度。
    2. **ELT规模扩展验证**：在10556致动器、121×121 PWFS参数下，验证网络结构与算法对高自由度系统的缩放性能。
    3. **数据失配鲁棒性测试**：在训练阶段注入剧烈变化的风场条件（风速减半、风向偏移90°），测试模型在大气条件突变时的泛化与自适应能力。
    4. **MagAO-X硬件在环实验**：仅控制woofer致动器阵列。采用相同CNN架构（3层卷积，历史帧数k=m=10），训练50个episode(25000帧)后继续运行5000帧，对比冕后PSF的斑点时间方差变化。
- **实验结果**：

| 实验设计 | 数据与环境参数 | 核心结果与性能提升 |
| :--- | :--- | :--- |
| **VLT仿真(低噪)** | 8m口径，1364致动器，非调制PWFS，0等星引导 | PO4AO实现对比度提升**3-5倍**，Strehl比达95.69（积分器约93.6）；推理延迟仅**0.30 ms**，满足实时性要求。 |
| **VLT仿真(高噪)** | 同上，9等星引导光子噪声环境 | 在噪声主导条件下，PO4AO残差控制仍优于积分器，对比度提升**3-9倍**，展现强抗噪鲁棒性。 |
| **ELT仿真扩展** | 40m口径，10556致动器，121×121 PWFS | 性能与VLT规模高度一致，推理时间稳定在**0.37 ms**，证明算法可无缝扩展至下一代极大望远镜。 |
| **数据失配测试** | 训练风场条件突变(风速-50%, 风向+90°)，测试原条件 | 在近星区控制范围内PO4AO对比度仍显著优于积分器，证明算法对大气湍流非平稳性具有强适应能力。 |
| **MagAO-X实验室** | MagAO-X硬件，woofer控制，风速5/15/30 m/s注入扰动 | 在2.4~6 $\lambda$/D区域内，冕后斑点时间方差降低**3-7倍**；仅需1万帧数据即超越积分器性能，验证了“纯数据驱动”在真实光学平台上的可行性。 |

### 核心结论
1. **性能突破与实时可行性**：PO4AO在数值模拟与MagAO-X硬件实验中均显著超越传统积分器控制器，对比度/斑点方差提升3-7倍；极快训练速度（约5-10秒）与亚毫秒级推理延迟（<0.4 ms）已满足地基极大望远镜XAO系统的实时闭环控制需求。
2. **强预测性与系统鲁棒性**：该方法作为纯数据驱动的预测控制器，能自适应补偿系统延迟、金字塔波前传感器的光学增益效应（OG）及严重的数据失配问题，无需依赖精确的物理先验模型或频繁的人工重校准。
3. **范式转换意义**：成功验证了“模型强化学习+可微策略优化”在极端自适应光学控制领域的有效性，为下一代高对比度成像系统提供了一种自动化、可扩展、高鲁棒性的控制架构，有望大幅提升系外行星直接成像的信噪比与观测效率。
