## 核心内容

### 背景与目标
- **研究背景**：极大口径望远镜（ELT）在宽视场观测中受大气湍流各向异性限制，传统单共轭自适应光学（AO）无法实现全视场均匀校正，亟需具备高实时性、高模块化与层析重构能力的MCAO地面测试平台与底层控制架构。
- **本文目标**：提出DAO4MATTO实时控制软件系统 → 通过基于NUMA共享内存的DAO开源架构与C/C++混合编程机制 → 实现MCAO测试台“光源模拟-湍流动态注入-波前传感-层析校正-性能评估”全链路高频（≥1 kHz）闭环控制，为ELT级光学系统研发提供可复现的国际通用验证环境。

### 研究内容
- **技术路线**：输入（LED自然导星/OLED激光导星模拟、电机化光学平台调谐） → 湍流动态注入（旋转相位屏生成~1 kHz相位畸变历史） → 波前传感（SLM相位掩模+GigE相机模拟各类WFS） → 实时控制核心（构建交互矩阵 → 伪逆求解层析重构矩阵 → ≥1 kHz矩阵-向量乘法MVM） → 执行器输出（多DM/FF-SLM/倾斜镜同步校正） → 输出/评估（科学相机获取PSF与残差分析）。
- **关键方法**：
  1. **DAO4MATTO模块化实时控制框架**：深度集成开源DAO（Durham Adaptive Optics）RTC包，底层使用C/C++保障低延迟与低抖动，上层使用Python负责逻辑编排。利用NUMA多核服务器的共享内存机制实现多进程数据零拷贝交换，支持硬件设备的即插即用与高度模块化配置，兼容各类新型波前传感与校正器件。
  2. **多共轭层析重构与高频同步控制算法**：针对MCAO系统多大气层独立校正需求，系统实时计算各控制通道到波前传感器的交互矩阵（Interaction Matrix），通过伪逆运算生成重构矩阵（Reconstruction Matrix）。在≥1 kHz的闭环频率下，以矩阵-向量乘法（MVM）高效完成从波前测量残差到各变形镜/调制器控制指令的映射，实现层析级的高频动态校正。

### 实验内容
- **数据**：本研究为光学工程与控制系统原型验证，未使用传统数据集。硬件实验基于MATTO测试台缩比原型，模拟典型ELT级自适应光学光路与大气湍流环境。
- **实验设计**：
  - **系统组成**：控制主机（3台Linux服务器搭载AMD EPYC 9648X CPU + 1台存储服务器 + 2台Windows工作站）；网络架构（25Gb/s与1Gb/s交换机）；执行与传感单元（ALPAO DM292变形镜(292致动器)、Shack-Hartmann波前传感器、FLI C-Blue One 1.7工业/科学相机）。
  - **环境与参数**：控制环路目标频率 ≥1 kHz；运行于Linux底层环境；光路模拟NGS与LGS双类型光源。
  - **复现指导**：搭建单共轭AO测试光路 → 接入SH-WFS与DM → 部署DAO4MATTO软件栈（NUMA内存池初始化与进程绑定） → 配置开环采集波前质心与瞳面图像 → 加载重构矩阵启动闭环 → 通过焦面相机记录PSF演变与控制延迟。
- **实验结果**：原型系统成功完成从开环传感到闭环校正的链路验证。由于本文为项目预研/技术报告性质，尚未提供基线对比、消融实验及具体定量性能指标（如斯特列比比Strehl Ratio提升、波前均方根RMS下降值）。主要结果为系统控制链路的稳定性、数据流低延迟特性与闭环校正功能的完整打通。

### 核心结论
1. **架构验证有效**：DAO4MATTO系统经原型测试，具备满足MCAO测试台≥1 kHz高频控制需求的实时数据处理能力，成功打通“模拟-传感-重构-校正”全链路闭环，验证了初始设计假设。
2. **模块化与可拓展性强**：基于NUMA共享内存与开源DAO框架的设计使系统具备极高的硬件兼容性，可灵活适配未来MATTO测试台的多共轭层析校正需求，避免传统RTC系统的“硬编码”瓶颈。
3. **研发路径明确**：当前工作已完成核心控制逻辑的原型部署与链路调通，完整版本计划于2026年底交付。该系统将作为国际通用平台，显著加速ELT级多共轭自适应光学技术的地面验证与工程化迭代（注：大规模多DM层析校正的定量光学性能需待完整平台建成后进一步评估）。
