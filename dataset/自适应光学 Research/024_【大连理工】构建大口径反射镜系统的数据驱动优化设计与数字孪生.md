# 大连理工构建大口径反射镜系统的数据驱动优化设计与数字孪生

大口径反射镜系统设计需要同时考虑光学面形、轻量化、支撑结构、温度变化和结构模态。传统优化往往受限于有限元分析耗时，高维变量空间中的可行设计搜索效率不高。大连理工大学 等提出大口径反射镜系统的数据驱动优化设计与数字孪生，把 45 维参数化镜面系统、约束多目标优化和数字孪生平台结合起来，用较少有限元样本完成设计搜索，并用 surrogate model 支撑快速响应。

## 45 维参数化镜面系统

论文对象是一套大口径 off-axis paraboloid mirror system。镜面直径为`612 mm`，厚度为`50 mm`，采用 open-back honeycomb lightweighting；背部为 nine-point Hindle support，侧向为 six-point A-frame support。镜体材料为 Zerodur，结构件材料为 Invar。作者建立了包含 mirror cavities、flexure posts、triangular plates、A-frame 和 mirror chamber 的`45`维参数化模型。

优化目标同时包括`RMS(0°,22°C)`、`RMS(0°,62°C)`和`MASS`，约束条件为`RMS(45°,22°C)<150`、`RMS(45°,62°C)<150`、`F0>100`。有限元分析在 ANSYS Workbench 中完成，硬件为 12-core CPU 2.2 GHz 和 16 GB RAM。这样的设置把设计问题明确为“轻量化、低波前误差和结构稳定性”的多目标约束搜索。

这类镜面设计的难点在于变量之间存在强耦合。减薄镜体或增大蜂窝腔可以降低质量，却可能削弱刚度并放大重力或温度引起的面形变化；支撑位置和柔性柱尺寸可以改善某个姿态下的 RMS，却可能让另一姿态或温度点超出约束。45 维模型把这些几何和支撑参数统一到一个搜索空间中，使算法可以同时评估质量、面形和基频，而不是靠人工逐项调参。

## 用 CNSGAIII-EHVI 降低有限元调用

作者提出 CNSGAIII-EHVI algorithm，在 NSGAIII-EHVI 框架中加入 PoF 和 non-dominated sorting constraint handling，用于约束多目标优化。整个优化只调用`100`次 FEA，参数包括`Ns=50`、`FEmax=100`、`tmax=15`、`Nuniform=10000`。对于高维镜面系统，这一点很关键，因为每一次全有限元计算都意味着明显的时间成本。

与 KTS 方法相比，CNSGAIII-EHVI 得到`32`个 feasible solutions，KTS 为`17`个；Pareto front 解数量为`14`，KTS 为`11`；HV 指标为`4.2220`，KTS 为`4.2214`。论文还报告 spacing 和 spread 指标在该算法下更有利，说明在有限 FEA 预算内，算法能得到更均匀、更多样的可行设计集合。这里的重点不是单一最优尺寸，而是给设计者提供一组可权衡质量、面形和约束的 Pareto 解。

只做`100`次 FEA 是本文优化部分的重要前提。对于实际镜面系统，每次有限元计算都涉及复杂网格、载荷和温度场，单纯增加样本数量并不经济。CNSGAIII-EHVI 通过期望超体积改进引导采样，又用约束处理机制避免算法在不可行区域浪费过多预算。最终得到更多 feasible solutions，意味着工程师可以在接近的光学性能下选择更轻、更稳或更易加工的方案。

## 数字孪生从分钟级变成秒级

在优化设计之外，论文还建立了 mirror system digital twin。作者使用 RBF-G surrogate model，以 deflection angle 和 temperature 作为输入，通过 Latin Hypercube Sampling 构造样本。有限元模型原始节点数为`963,495`，经 node reduction 后降至`92,466`个节点。可视化部分基于 Unity3D，Zernike fitting 则通过 MATLAB .dll 完成。

性能对比显示，传统 FEA + Matlab 约需`240 s`；单独 surrogate model 可在`<1 s`内给出 RMS/PV；digital twin 在`<2 s`内输出 RMS、PV 和 contour map，结构 deformation response 低于`50 ms`。精度方面，surrogate model 的`R2`为`0.99915`，digital twin 的`R2`为`0.99971`。这说明数字孪生并不是替代全部有限元细节，而是在给定参数空间内提供快速近似和可视化反馈。

## 研究意义与边界

这项工作的特点是把“设计搜索”和“运行响应”放在同一数据驱动框架下。前者用 CNSGAIII-EHVI 在有限 FEA 次数内寻找约束 Pareto 解，后者用 surrogate model 和数字孪生把不同姿态、温度下的面形响应快速呈现出来。对于大口径镜面系统，这种流程有助于在早期设计中更快比较支撑、轻量化和质量约束之间的关系。

需要注意的是，数字孪生的可信度依赖训练样本覆盖范围、有限元模型质量和参数化假设。如果镜面结构、材料参数或工作边界超出建模范围，仍需要回到高保真 FEA 或实验验证。论文的贡献在于给出一套可复用的数据驱动工程流程，而不是取消物理建模和验证环节。

数字孪生部分还提供了一个面向使用阶段的接口：设计人员可以改变角度和温度，快速查看 RMS、PV、Zernike 拟合结果和变形云图。相比只输出少量指标的 surrogate model，Unity3D 平台把结构响应和波前结果放在同一界面中，更便于检查某个设计在不同工况下的趋势。其学术意义在于把优化、代理模型和可视化闭环连接起来，使大口径镜面系统从方案比较到状态评估都能使用同一套数据链。

从工程流程看，这种数字孪生并不是在设计完成后附加的展示工具，而是可以反过来服务设计迭代。优化阶段得到的 Pareto 解可以输入平台，快速比较不同角度和温度下的 RMS/PV；若某个解在可视化中表现出局部变形集中，设计人员可以回到参数化模型调整蜂窝腔、支撑或镜室参数。论文把`R2=0.99971`和`<2 s`响应放在一起报告，说明其目标是在保持接近有限元结果的同时，让设计评估从等待计算转向交互式检查。
